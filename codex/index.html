01

极限：接近，不必到达

極限 / 数列与函数的极限，是微积分的起点。

CONCEPT / 核心概念

当输入越来越接近一个值

\(x\) 趋近 \(a\) 时，如果 \(f(x)\) 趋近固定值 \(L\)，就写作：

\[\lim_{x\to a}f(x)=L\]

极限看的是附近的变化，与 \(f(a)\) 是否有定义不同。左右极限相等，双侧极限才存在；例如 \(1/x\) 在 \(x\to0\) 时左右趋向不同，双侧极限不存在。

连续的条件：\(\displaystyle\lim_{x\to a}f(x)=f(a)\)。

TOOLKIT / 常用极限

先判断，再选择变形

\[\lim_{x\to0}\frac{\sin x}{x}=1,\qquad\lim_{n\to\infty}\frac1{n}=0\]\[\lim_{n\to\infty}r^n=0\quad(|r|<1)\]

三角极限中的角使用弧度。遇到 \(0/0\) 先因式分解、约分或有理化；无穷远处的有理式可同除以最高次幂。

无穷等比级数：\(\sum_{n=0}^{\infty}ar^n=\frac{a}{1-r}\)，条件为 \(|r|<1\)。一般无穷级数看部分和是否收敛。

WORKED EXAMPLE / 原创 EJU 风格填空例题 01

把“无法直接代入”变成可以计算

\(\displaystyle\lim_{x\to2}\frac{x^2-4}{x-2}=\boxed{\text{A}}\)，则 A = 4。

解题：当 \(x\ne2\) 时，\(\frac{(x-2)(x+2)}{x-2}=x+2\)，再令 \(x\to2\)，得到 4。约分只要求接近过程中的 \(x\ne2\)。

不要把 \(0/0\) 当作答案。它表示直接代入不能确定极限，需要继续变形。
02

微分：给变化一个精确的速度

微分法 / 从求导法则，到切线、极值与函数图像。

导数就是切线的斜率

\[f'(a)=\lim_{h\to0}\frac{f(a+h)-f(a)}h\]\[y-f(a)=f'(a)(x-a)\]

差商是割线的斜率；当两点无限接近，得到切线。\(f'(a)\) 是一点的导数值，\(f'(x)\) 是导函数。

例如 \(f(x)=x^2\)，则 \(f'(x)=2x\)；在 \(x=1\) 处的切线为 \(y=2x-1\)。

求导法则：先认结构

\[(u+v)'=u'+v',\quad(cu)'=cu'\]\[(uv)'=u'v+uv',\quad\left(\frac uv\right)'=\frac{u'v-uv'}{v^2}\]\[(f(g(x)))'=f'(g(x))g'(x)\]

商法则要求 \(v\ne0\)。复合函数从外到内求导，再乘内层导数：\(\bigl(\sin(x^2)\bigr)'=2x\cos(x^2)\)。

基本导数速查

函数导函数使用条件
\(x^r\)\(rx^{r-1}\)在函数可微的定义域内；一般实数幂可取 \(x>0\)
\(\sin x,\ \cos x,\ \tan x\)\(\cos x,\ -\sin x,\ 1/\cos^2x\)弧度制；正切要求 \(\cos x\ne0\)
\(e^x,\ a^x\)\(e^x,\ a^x\ln a\)\(a>0,\ a\ne1\)
\(\ln x,\ \log_a x\)\(1/x,\ 1/(x\ln a)\)\(x>0;\ a>0,\ a\ne1\)

READ THE GRAPH / 增减与极值

求导 → 找临界点 → 判断变号

在一个区间内，\(f'(x)>0\) 则递增，\(f'(x)<0\) 则递减。导数由正变负对应极大值，由负变正对应极小值。

以 \(f(x)=x^3-3x\) 为例，\(f'(x)=3(x-1)(x+1)\)：

\(f\)↗极大 2↘极小 −2↗
\(f'(a)=0\) 不保证极值：\(x^3\) 在 0 处导数为 0，却一直递增。闭区间上的最大、最小值还要比较端点。
SHAPE / 用二阶导数补全图像

除了增减，还要看弯曲方向

\(f''(x)>0\)：斜率递增，图像像 ∪，日语称「下に凸」。\(f''(x)<0\)：斜率递减，图像像 ∩，称「上に凸」。

拐点需要图像凹凸性发生改变，不能仅凭 \(f''(a)=0\) 判断。对 \(x^3-3x\)，\(f''(x)=6x\)，因此 \((0,0)\) 是拐点。

画图顺序：定义域 → 对称性与截距 → 增减与极值 → 凹凸与拐点 → 边界极限及渐近线。

二阶判别：若 \(f'(a)=0\)，则 \(f''(a)>0\) 时为极小值，\(f''(a)<0\) 时为极大值；等于 0 时需进一步判断。

03

积分：把微小变化累积起来

積分法 / 原函数、定积分，以及换元与分部两种基本方法。

不定积分与定积分

若 \(F'(x)=f(x)\)，则 \(F\) 是 \(f\) 的一个原函数。

\[\int f(x)\,dx=F(x)+C\]\[\int_a^b f(x)\,dx=F(b)-F(a)\]

第二式是微积分基本定理的常用形式（\(f\) 连续）。不定积分要写任意常数 \(C\)；定积分是一个数，不再加 \(C\)。

\[\int x^r\,dx=\frac{x^{r+1}}{r+1}+C\quad(r\ne-1)\]\[\int\frac1x\,dx=\ln|x|+C\quad(x\ne0)\]\[\int e^x\,dx=e^x+C\]\[\int\cos x\,dx=\sin x+C,\quad\int\sin x\,dx=-\cos x+C\]

幂函数公式需在相应实数定义域的区间内使用。定积分满足线性、区间可加性，并且交换上下限会变号。

METHOD 01 / 换元积分

认出“内层函数及其导数”

\[\int f(g(x))g'(x)\,dx=\int f(u)\,du,\quad u=g(x)\]

例：令 \(u=x^2+1\)，\(du=2x\,dx\)。

\[\int_0^1 2x(x^2+1)^3\,dx=\int_1^2u^3\,du\]\[=\left[\frac{u^4}4\right]_1^2=\frac{15}4\]

定积分换元时，上下限也随之改变：\(x=0\to u=1\)，\(x=1\to u=2\)。

换元后变量要统一，不能同时保留 \(u\) 和未替换的 \(x\)。不定积分最后应代回原变量。
METHOD 02 / 分部积分

把一个乘积变得更容易积分

\[\int u\,dv=uv-\int v\,du\]

常把求导后变简单的因子选作 \(u\)，例如多项式或 \(\ln x\)；另一个因子必须容易积分。

例：\(u=x,\ dv=e^x dx\)，则 \(du=dx,\ v=e^x\)。

\[\int xe^x\,dx=xe^x-e^x+C\]\[\int_0^1 xe^x\,dx=\left[(x-1)e^x\right]_0^1=1\]
CHOOSE A METHOD / 计算前的判断

先整理，再选方法

  1. 多项式的和：展开后逐项积分。
  2. 复合函数乘内层导数：优先考虑换元。
  3. 多项式乘指数、三角函数：尝试分部。
  4. 分式或三角式：先约分、拆分或使用恒等式。

最后反向检查：对不定积分结果求导，应该回到原被积函数。

例如 \(\int\frac{2x}{x^2+1}dx=\ln(x^2+1)+C\)，因为分子恰好是分母的导数。

04

从积分到面积与体积

積分の応用 / 先画示意图，再确定边界与截面。

面积：上方曲线减下方曲线

\[S=\int_a^b|f(x)-g(x)|\,dx\]

若在 \([a,b]\) 上 \(f\ge g\)，可直接积 \(f-g\)；曲线上下位置变化时，先求交点，再分段积分。

例：\(y=x\) 与 \(y=x^2\) 交于 \(x=0,1\)，区间内 \(x\ge x^2\)。

\[S=\int_0^1(x-x^2)\,dx=\frac16\]
定积分是带符号的累积，面积总是非负。\(\int_{-1}^1x\,dx=0\)，但图像与 x 轴围成的总面积为 1。

体积：沿轴累加截面积

\[V=\int_a^b A(x)\,dx\]\[V=\pi\int_a^b\bigl(R(x)^2-r(x)^2\bigr)\,dx\]

第二式用于绕 x 轴旋转的圆环截面，\(R\ge r\ge0\) 分别是外、内半径。实心圆盘取 \(r=0\)。

例：\(0\le x\le1\) 内，\(y=x\) 与 x 轴之间的区域绕 x 轴旋转：

\[V=\pi\int_0^1x^2\,dx=\frac\pi3\]

注意：被平方的是到旋转轴的距离，应先确认区域与旋转轴的相对位置。

停下来，自己算一遍

以下均为原创 EJU 风格填空题，并非 JASSO 历年真题；方框采用教学简化格式。

已展开 0 / 6 道解析 · 建议先独立作答，再核对过程

01 / 极限

基础

\(\displaystyle\lim_{x\to0}\frac{\sin 3x}{x}=\boxed{\text{A}}\)，则 A = ?。

A = 3。

\(\frac{\sin3x}{x}=3\frac{\sin3x}{3x}\)，后一个比值趋于 1。注意使用弧度制。

02 / 求导与切线

基础

曲线 \(y=x^3-2x\) 在 \(x=1\) 处的切线为 \(y=\boxed{\text{A}}x+\boxed{\text{B}}\)。

A = 1，B = −2。

\(f(1)=-1\)，\(f'(x)=3x^2-2\)，\(f'(1)=1\)。故 \(y+1=x-1\)。

03 / 闭区间最值

进阶

\(f(x)=x^3-3x\) 在 \([-2,2]\) 上的最大值为 \(\boxed{\text{A}}\)，最小值为 \(\boxed{\text{B}}\)。

A = 2，B = −2。

临界点为 \(x=\pm1\)。比较 \(f(-2)=-2,f(-1)=2,f(1)=-2,f(2)=2\)。最大值在 −1、2 处取得，最小值在 −2、1 处取得。

04 / 换元积分

基础

\(\displaystyle\int_0^1\frac{2x}{1+x^2}\,dx=\ln\boxed{\text{A}}\)，则 A = ?。

A = 2。

令 \(u=1+x^2\)，则原式 \(=\int_1^2\frac1u du=\ln2-\ln1=\ln2\)。

05 / 分部积分

进阶

\(\displaystyle\int_1^e\ln x\,dx=\boxed{\text{A}}\)，则 A = ?。

A = 1。

取 \(u=\ln x,dv=dx\)，得 \(\int\ln x\,dx=x\ln x-x+C\)。代入上下限：\((e-e)-(0-1)=1\)。

06 / 面积与旋转体

综合

在 \(0\le x\le1\) 上，\(y=x\) 与 \(y=x^2\) 围成区域的面积为 \(1/\boxed{\text{A}}\)，绕 x 轴旋转的体积为 \(2\pi/\boxed{\text{B}}\)。

A = 6，B = 15。

面积 \(S=\int_0^1(x-x^2)dx=1/6\)。外半径 \(x\)，内半径 \(x^2\)，故 \(V=\pi\int_0^1(x^2-x^4)dx=2\pi/15\)。注意是平方之差，不是差的平方。
