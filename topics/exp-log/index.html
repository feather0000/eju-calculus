1 指数的扩张

指数の拡張 — 累乗根・有理数の指数・実数の指数

指数最初只表示“乘几次”。为了让指数律继续成立，人们把它一步步扩张（拡張）：正整数 → $0$ 和负整数 → 有理数 → 实数。

为什么成立：扩张不是随意规定的，原则只有一条：让 $a^m a^n=a^{m+n}$ 继续成立。指数的含义因此逐步推广：正整数指数表示“连乘”，$0$ 和负整数指数由“相除”得到，有理数指数由“开方”得到，无理数指数由“逼近”得到。每一步都不改变原来的运算规则，所以下面所有公式都能用同一条指数律推出来。

补充例题　用扩张后的指数计算原创

计算 $4^{-\frac32}\times 8^{\frac23}\times 5^0$。

  1. 先处理最简单的：$5^0=1$。
  2. 统一成底 $2$：$4=2^2$，$8=2^3$。
  3. 用 $(a^r)^s=a^{rs}$：$4^{-\frac32}=2^{2\cdot(-\frac32)}=2^{-3}$，$8^{\frac23}=2^{3\cdot\frac23}=2^2$。
  4. 指数相加：$2^{-3}\times2^2\times1=2^{-1}=\dfrac12$。

答案：$\dfrac12$。

常见错误：

  • 把 $a^{-n}$ 当成负数。其实 $a>0$ 时 $a^{-n}$ 总是正数，如 $2^{-3}=\dfrac18>0$。
  • 不统一底就硬算，如把 $4^{-\frac32}$ 和 $8^{\frac23}$ 分别估算成小数，既慢又不精确。
  • 把 $5^0$ 算成 $0$ 或 $5$；任何非零数的 $0$ 次方都是 $1$。

EJU 应试提示：计算题先扫一眼底数：$4,8,16,32$ 想到 $2$，$9,27,81$ 想到 $3$，$25,125$ 想到 $5$。考试不能用计算器，“化同底”几乎总是最短的路线。

日语术语：累乗（るいじょう）：乘方、幂；指数（しすう）：指数；拡張（かくちょう）：扩张。

1.1 零指数与负指数

设 $a\ne 0$，$n$ 为正整数：

$$a^0=1,\qquad a^{-n}=\frac{1}{a^n}$$

例如 $2^{-3}=\dfrac18$。

为什么成立：要使 $a^m a^n=a^{m+n}$ 在 $n=0$ 时成立，需要 $a^m\cdot a^0=a^m$，两边除以 $a^m$（$a\ne0$）得 $a^0=1$。再取 $m=-n$：$a^{-n}\cdot a^{n}=a^{0}=1$，所以 $a^{-n}$ 只能是 $\dfrac{1}{a^n}$。条件 $a\ne0$ 正是因为这里要除以 $a^n$；$0^{-1}$ 相当于 $\dfrac10$，没有意义。

补充例题　负指数的分式原创

计算：(1) $\dfrac{3^{-2}+3^0}{3^{-1}}$；(2) $\left(2^{-1}+4^{-1}\right)^{-1}$。

  1. (1) 分子：$3^{-2}+3^0=\dfrac19+1=\dfrac{10}{9}$。
  2. (1) 分母：$3^{-1}=\dfrac13$，除以 $\dfrac13$ 就是乘 $3$，所以结果为 $\dfrac{10}{9}\times3=\dfrac{10}{3}$。
  3. (2) 先算括号内：$2^{-1}+4^{-1}=\dfrac12+\dfrac14=\dfrac34$。
  4. (2) 再取倒数：$\left(\dfrac34\right)^{-1}=\dfrac43$。

答案：(1) $\dfrac{10}{3}$；(2) $\dfrac43$。

常见错误：

  • $(a+b)^{-1}\ne a^{-1}+b^{-1}$。指数律只对“积”分配，对“和”不分配。上题 (2) 若误算为 $2+4=6$ 就错了。
  • $\left(\dfrac{a}{b}\right)^{-1}$ 是 $\dfrac{b}{a}$（取倒数），不是 $-\dfrac{a}{b}$（取相反数）。
  • $-2^{-2}$ 与 $(-2)^{-2}$ 不同：前者为 $-\dfrac14$，后者为 $\dfrac14$。

EJU 应试提示：分式中混有负指数时，分子分母同乘一个合适的幂，能一次去掉所有负指数。上题 (1) 同乘 $3^2$，得 $\dfrac{1+9}{3}=\dfrac{10}{3}$，这也是一种快速验算。

日语术语：負の指数（ふのしすう）：负指数；0乗（ゼロじょう）：零次方；逆数（ぎゃくすう）：倒数。

1.2 $n$ 次方根（累乗根）

$n$ 次方等于 $a$ 的数叫 $a$ 的 $n$ 次方根（$n$ 乗根）。实数范围内：

  • $n$ 为奇数：恰有一个，记作 $\sqrt[n]{a}$，$a$ 可以为负，如 $\sqrt[3]{-8}=-2$。
  • $n$ 为偶数且 $a>0$：有正负两个，$\sqrt[n]{a}$ 只表示正的那个，如 $\sqrt[4]{16}=2$，另一个是 $-\sqrt[4]{16}=-2$。

设 $a>0,\ b>0$，$m,n,k$ 为正整数：

$$\sqrt[n]{a}\,\sqrt[n]{b}=\sqrt[n]{ab}$$
$$\frac{\sqrt[n]{a}}{\sqrt[n]{b}}=\sqrt[n]{\frac{a}{b}}$$
$$\bigl(\sqrt[n]{a}\bigr)^m=\sqrt[n]{a^m}$$
$$\sqrt[m]{\sqrt[n]{a}}=\sqrt[mn]{a}$$

为什么成立：实数范围内方程 $x^n=a$ 的解，就是曲线 $y=x^n$ 与水平线 $y=a$ 的交点。$n$ 为奇数时 $y=x^n$ 单调递增，值域为全体实数，所以恰有一个交点；$n$ 为偶数时曲线关于 $y$ 轴对称且 $y\ge0$，所以 $a>0$ 时有两个交点，$a=0$ 时只有 $x=0$，$a<0$ 时没有实数解。根式公式的证法相同：例如 $\left(\sqrt[n]{a}\sqrt[n]{b}\right)^n=ab$，而 $\sqrt[n]{a}\sqrt[n]{b}>0$，正的 $n$ 次方根只有一个，所以它就是 $\sqrt[n]{ab}$。同理，$\left(\sqrt[m]{\sqrt[n]{a}}\right)^{mn}=a$，得到 $\sqrt[m]{\sqrt[n]{a}}=\sqrt[mn]{a}$。

补充例题　根式运算与实数根原创

(1) 化简 $\sqrt[3]{24}\cdot\sqrt[3]{9}$、$\sqrt[4]{48}\div\sqrt[4]{3}$、$\sqrt[3]{\sqrt{64}}$。(2) 求实数解：$x^4=81$；$x^3=-27$。

  1. (1) 同次根号可以合并：$\sqrt[3]{24}\cdot\sqrt[3]{9}=\sqrt[3]{216}=\sqrt[3]{6^3}=6$。
  2. (1) $\sqrt[4]{48}\div\sqrt[4]{3}=\sqrt[4]{\dfrac{48}{3}}=\sqrt[4]{16}=2$。
  3. (1) 根号套根号，次数相乘：$\sqrt[3]{\sqrt{64}}=\sqrt[6]{64}=\sqrt[6]{2^6}=2$。
  4. (2) $4$ 是偶数且 $81>0$，有正负两个实数解：$x=\pm\sqrt[4]{81}=\pm3$。
  5. (2) $3$ 是奇数，只有一个实数解：$x=\sqrt[3]{-27}=-3$。

答案：(1) $6$，$2$，$2$；(2) $x=\pm3$；$x=-3$。

常见错误：

  • 把 $\sqrt[4]{16}$ 写成 $\pm2$。根号记号 $\sqrt[n]{a}$（$n$ 为偶数）只表示正的那个值。而“$16$ 的 $4$ 次方根”是 $\pm2$ 两个数，要分清两种说法。
  • 解 $x^4=81$ 时漏掉 $x=-3$。
  • 不同次的根号直接相乘，如把 $\sqrt{2}\cdot\sqrt[3]{2}$ 写成 $\sqrt[6]{4}$。正确做法是化成指数：$2^{\frac12+\frac13}=2^{\frac56}=\sqrt[6]{32}$。

EJU 应试提示：看题干的措辞：$a$ の $n$ 乗根 问的是所有解；$\sqrt[n]{a}$ 是一个确定的数。遇到次数不同的根号，一律先改写成分数指数。

日语术语：累乗根（るいじょうこん）：方根；平方根（へいほうこん）：平方根；立方根（りっぽうこん）：立方根；実数解（じっすうかい）：实数解。

1.3 有理数指数与指数律

设 $a>0$，$m$ 为整数，$n$ 为正整数：

$$a^{\frac{m}{n}}=\sqrt[n]{a^m}$$

例如 $8^{\frac23}=(\sqrt[3]{8})^2=4$，$16^{\frac34}=8$，$27^{-\frac13}=\dfrac13$。再用有理数逼近无理数，就能定义任意实数指数（如 $2^{\sqrt2}$）。对 $a>0,\ b>0$ 和任意实数 $r,s$，指数律（指数法則）成立：

$$a^r a^s=a^{r+s}$$
$$\frac{a^r}{a^s}=a^{r-s}$$
$$(a^r)^s=a^{rs}$$
$$(ab)^r=a^r b^r$$

计算技巧：先把所有数化成同一个底的幂。例如 $2^{\frac12}\times 2^{\frac13}\div 2^{-\frac16}=2^{\frac12+\frac13+\frac16}=2$。

易错：有理数指数的前提是底 $a>0$。$\sqrt[3]{-8}$ 有意义，但不写成 $(-8)^{\frac13}$。另外，$\sqrt{x^2}=|x|$，不一定等于 $x$。

对称式常用结论：令 $t=a^x+a^{-x}$，由 $a^x\cdot a^{-x}=1$ 得

$$a^{2x}+a^{-2x}=t^2-2,\qquad a^{3x}+a^{-3x}=t^3-3t.$$

为什么成立：若要 $(a^r)^s=a^{rs}$ 对有理数也成立，则 $\left(a^{\frac{m}{n}}\right)^n=a^m$，说明 $a^{\frac{m}{n}}$ 是 $a^m$ 的 $n$ 次方根；取正的那个，就得到 $a^{\frac{m}{n}}=\sqrt[n]{a^m}$。要求 $a>0$ 是为了让定义不产生矛盾：若允许 $(-8)^{\frac13}=-2$，由 $\dfrac13=\dfrac26$ 又应有 $(-8)^{\frac26}=\sqrt[6]{(-8)^2}=\sqrt[6]{64}=2$，同一个指数得出两个值。上面的对称式结论只是展开：$(a^x+a^{-x})^2=a^{2x}+2+a^{-2x}$，$(a^x+a^{-x})^3=a^{3x}+3a^x+3a^{-x}+a^{-3x}=a^{3x}+a^{-3x}+3t$。

补充例题　根式化指数与整体代入原创

(1) 设 $a>0$，化简 $\sqrt{a\sqrt[3]{a^2}}\div a^{\frac13}$。(2) 设 $a>0$，$a^{2x}=3$，求 $\dfrac{a^{3x}+a^{-3x}}{a^x+a^{-x}}$。

  1. (1) 从里到外写成指数：$\sqrt[3]{a^2}=a^{\frac23}$，所以 $a\sqrt[3]{a^2}=a^{1+\frac23}=a^{\frac53}$。
  2. (1) 再开平方：$\sqrt{a^{\frac53}}=a^{\frac56}$。
  3. (1) 除以 $a^{\frac13}$：$a^{\frac56-\frac13}=a^{\frac12}=\sqrt a$。
  4. (2) 把分子看成立方和：$p^3+q^3=(p+q)(p^2-pq+q^2)$，其中 $p=a^x$，$q=a^{-x}$，且 $pq=1$。
  5. (2) 分母 $p+q>0$，可以约去：原式 $=a^{2x}-1+a^{-2x}$。
  6. (2) 代入 $a^{2x}=3$，$a^{-2x}=\dfrac13$：$3-1+\dfrac13=\dfrac73$。

答案：(1) $\sqrt a$；(2) $\dfrac73$。

常见错误：

  • $a^r+a^s\ne a^{r+s}$。指数相加对应的是“乘”，不是“加”。
  • $(a^r)^s$ 与 $a^{r^s}$ 混淆：$(2^3)^2=2^6$，而 $2^{3^2}=2^9$。
  • 对称式代入时漏掉中间项：$(a^x+a^{-x})^2$ 展开后的常数项是 $2$，因为 $a^x\cdot a^{-x}=1$。

EJU 应试提示：见到 $a^{2x}$ 已知而求 $a^{3x}$ 之类的题，不必解出 $a$ 或 $x$，用因式分解或平方、立方公式整体代入。填空题的形式通常也在暗示这条路。

日语术语：指数法則（しすうほうそく）：指数律；有理数（ゆうりすう）：有理数；無理数（むりすう）：无理数；因数分解（いんすうぶんかい）：因式分解。

2 指数函数与图像

指数関数とグラフ

$y=a^x$（$a>0,\ a\ne1$）叫指数函数（指数関数），$a$ 叫底（底）。规定 $a\ne1$，因为 $1^x$ 恒为 $1$，只是常数函数。

性质$a>1$$0<a<1$
定义域（定義域）全体实数
值域（値域）$y>0$
必过的点$(0,1)$ 和 $(1,a)$
渐近线（漸近線）$x$ 轴（$y=0$）
单调性单调递增：$x_1<x_2\iff a^{x_1}<a^{x_2}$单调递减：$x_1<x_2\iff a^{x_1}>a^{x_2}$

为什么成立：设 $a>1$，$r>0$，则 $a^r>1$。当 $x_1<x_2$ 时，$a^{x_2}-a^{x_1}=a^{x_1}\left(a^{x_2-x_1}-1\right)>0$，所以函数递增。$0<a<1$ 时，$\dfrac1a>1$，而 $a^x=\left(\dfrac1a\right)^{-x}$，自变量变号，所以函数递减，图像与 $y=\left(\dfrac1a\right)^x$ 关于 $y$ 轴对称。$a^0=1$ 说明所有曲线都过 $(0,1)$；$a>1$ 时 $x\to-\infty$ 则 $a^x\to0$ 但始终为正，因此 $x$ 轴是渐近线，值域是 $y>0$。

补充例题　利用单调性比较大小原创

(1) 将 $\sqrt2,\ \sqrt[3]{4},\ \sqrt[5]{8},\ \sqrt[7]{16}$ 按从小到大排列。(2) 比较 $0.5^{0.3}$ 与 $0.5^{0.4}$。

  1. (1) 全部化成底 $2$：$2^{\frac12},\ 2^{\frac23},\ 2^{\frac35},\ 2^{\frac47}$。
  2. (1) 底 $2>1$，函数递增，只需比较指数。通分（分母 $210$）：$\dfrac12=\dfrac{105}{210}$，$\dfrac47=\dfrac{120}{210}$，$\dfrac35=\dfrac{126}{210}$，$\dfrac23=\dfrac{140}{210}$。
  3. (1) 所以 $2^{\frac12}<2^{\frac47}<2^{\frac35}<2^{\frac23}$。
  4. (2) 底 $0.5<1$，函数递减。因为 $0.3<0.4$，所以 $0.5^{0.3}>0.5^{0.4}$。

答案：(1) $\sqrt2<\sqrt[7]{16}<\sqrt[5]{8}<\sqrt[3]{4}$；(2) $0.5^{0.3}>0.5^{0.4}$。

常见错误：

  • 看到指数大就断定值大，忽略了底小于 $1$ 的情形。
  • 认为 $y=a^x$ 的值可以等于 $0$。曲线只是无限接近 $x$ 轴，永远不与它相交。
  • 把 $y=2^x$ 与 $y=x^2$ 混淆：前者变量在指数上，后者变量在底上，图像和性质完全不同。

EJU 应试提示：比较大小分两类：能化同底就比较指数；能化同指数（如取公倍数次方）就比较底，练习 4 用的就是后一种。先判断底与 $1$ 的大小，再写不等号。

日语术语：指数関数（しすうかんすう）：指数函数；底（てい）：底；単調増加（たんちょうぞうか）：单调递增；単調減少（たんちょうげんしょう）：单调递减；漸近線（ぜんきんせん）：渐近线。

2.1 图像变换

$y=a^{x-p}+q$ 是把 $y=a^x$ 向右平移 $p$、向上平移 $q$（平行移動），渐近线变为 $y=q$。例如 $y=2^{x-1}+3$ 的渐近线是 $y=3$，图像过点 $(1,4)$。

为什么成立：设 $(X,Y)$ 在 $y=a^x$ 上，把它向右移 $p$、向上移 $q$ 得到点 $(x,y)=(X+p,Y+q)$。反解 $X=x-p$，$Y=y-q$，代入 $Y=a^X$ 得 $y-q=a^{x-p}$，这就是为什么“向右移”在式子里是减 $p$。对称变换同理：关于 $y$ 轴对称，把 $x$ 换成 $-x$，得 $y=a^{-x}$；关于 $x$ 轴对称，把 $y$ 换成 $-y$，得 $y=-a^x$。此外，系数可以并入指数：$4\cdot2^x=2^{x+2}$，所以对指数函数来说，“乘常数”等于“左右平移”。

补充例题　平移、渐近线与截距原创

对函数 $y=8\cdot2^x-3$：(1) 它由 $y=2^x$ 怎样平移得到？(2) 求渐近线。(3) 求与 $y$ 轴、$x$ 轴的交点。

  1. (1) 把系数并入指数：$8\cdot2^x=2^3\cdot2^x=2^{x+3}$，所以 $y=2^{x+3}-3$。与 $y=a^{x-p}+q$ 对照，$p=-3$，$q=-3$，即向左平移 $3$、向下平移 $3$。
  2. (2) $y=2^x$ 的渐近线 $y=0$ 向下平移 $3$，得 $y=-3$（左右平移不改变水平线）。
  3. (3) 令 $x=0$：$y=8\cdot1-3=5$，交点为 $(0,5)$。
  4. (3) 令 $y=0$：$2^{x+3}=3$，所以 $x+3=\log_2 3$，$x=\log_2 3-3$，交点为 $(\log_2 3-3,\ 0)$。

答案：(1) 向左平移 $3$、向下平移 $3$；(2) $y=-3$；(3) $(0,5)$，$(\log_2 3-3,\ 0)$。

常见错误：

  • $y=2^{x+3}$ 是向左平移 $3$，不是向右。
  • 认为平移后渐近线仍是 $x$ 轴。上下平移 $q$，渐近线随之变为 $y=q$。
  • 把 $8\cdot2^x$ 算成 $16^x$。系数不能并入底，只能写成 $2^{x+3}$。

EJU 应试提示：求值域也靠渐近线：$y=2^{x+3}-3$ 的值域是 $y>-3$。画草图时先画渐近线，再标一个容易算的点（如 $x=-3$ 时 $y=-2$），方向和位置基本就确定了。

日语术语：平行移動（へいこういどう）：平移；対称移動（たいしょういどう）：对称变换；交点（こうてん）：交点；$y$ 切片（ワイせっぺん）：$y$ 截距。

2.2 方程与不等式

第一步都是化成同底，然后比较指数：

  • 方程：$8^x=4\Rightarrow 2^{3x}=2^2\Rightarrow x=\dfrac23$。
  • 不等式，$a>1$ 时不等号方向不变，$0<a<1$ 时方向反转：$\left(\dfrac12\right)^x>4=\left(\dfrac12\right)^{-2}\Rightarrow x<-2$。

换元必写范围：令 $t=a^x$ 时一定有 $t>0$；若 $x$ 有范围，$t$ 的范围也要跟着变。很多题正是靠这一点舍去负根，或确定最大、最小值。

为什么成立：指数函数是单调的，所以 $a^{x_1}=a^{x_2}\iff x_1=x_2$：同一个函数值只对应一个 $x$，这就是可以“去掉底、比较指数”的依据。不等式的方向取决于单调性：递增时大小关系保持，递减时大小关系颠倒。换元后的范围也来自函数性质：$t=a^x$ 的值域是 $t>0$，所以 $t\le0$ 的根都要舍去。

补充例题　指数方程与底小于 1 的不等式原创

(1) 解方程 $9^x-8\cdot3^x-9=0$。(2) 解不等式 $\left(\dfrac12\right)^{2x-1}\le\left(\dfrac12\right)^{x+2}$。

  1. (1) $9^x=(3^x)^2$，令 $t=3^x$，并写明 $t>0$。方程化为 $t^2-8t-9=0$。
  2. (1) 因式分解：$(t-9)(t+1)=0$，$t=9$ 或 $t=-1$。
  3. (1) 由 $t>0$ 舍去 $t=-1$。$3^x=9=3^2$，所以 $x=2$。
  4. (1) 代回检验：$81-72-9=0$，成立。
  5. (2) 两边已是同底，底 $\dfrac12<1$，函数递减，去底时不等号反向：$2x-1\ge x+2$。
  6. (2) 移项得 $x\ge3$。

答案：(1) $x=2$；(2) $x\ge3$。

常见错误：

  • 换元后没写 $t>0$，把 $3^x=-1$ 当作有解，或为它强行找一个 $x$。
  • 底小于 $1$ 时忘记反向。注意 $\left(\dfrac12\right)^x$ 与 $2^{-x}$ 相同，化成底 $2$ 再解可以用来检查方向。
  • 把 $3^{x+1}$ 换成 $t+1$。正确的是 $3^{x+1}=3\cdot3^x=3t$。

EJU 应试提示：看到 $4^x$ 与 $2^x$、$9^x$ 与 $3^x$ 同时出现，几乎一定要换元。答案若要填 $x$ 的值，换元后别停在 $t$ 的值上，记得换回去。

日语术语：指数方程式（しすうほうていしき）：指数方程；指数不等式（しすうふとうしき）：指数不等式；置き換え（おきかえ）：换元；不等号の向き（ふとうごうのむき）：不等号的方向。

2.3 含参数的指数方程：实数解的个数

形如 $4^x-p\cdot2^x+k=0$ 的方程，令 $t=2^x$ 后化为 $t$ 的二次方程。因为 $t=2^x$ 是一一对应（每个 $t>0$ 恰对应一个 $x$），所以$x$ 的实数解个数 $=$ 满足 $t>0$ 的 $t$ 的解个数。把方程写成 $-k=t^2-pt$（参数分离，定数分離），就变成“抛物线 $y=t^2-pt\ (t>0)$ 与水平线 $y=-k$ 的交点个数”。

易错：抛物线只画 $t>0$ 的部分，端点 $t=0$ 取不到（画空心点）；若 $x$ 另有范围（如 $x\ge1$），$t$ 的范围也随之变为 $t\ge2$，端点能否取到要重新判断。

日语术语：実数解の個数（じっすうかいのこすう）：实数解的个数；定数分離（ていすうぶんり）：参数分离。

3 对数的性质

対数の定義と性質・底の変換公式

对 $a>0,\ a\ne1,\ M>0$，定义对数（対数）：

$$a^p=M\iff p=\log_a M$$

$a$ 叫底（底），$M$ 叫真数（真数）。一句话：$\log_a M$ 就是“$a$ 的几次方等于 $M$”。例如 $\log_2 8=3$，$\log_3\dfrac19=-2$，$\log_{10}0.01=-2$，$\log_9 27=\dfrac32$。

为什么成立：对数是为了回答“指数是多少”而引入的。$a>0,\ a\ne1$ 时，$y=a^x$ 单调且值域为 $y>0$，所以每个 $M>0$ 都恰好对应一个指数 $p$，$\log_a M$ 才有唯一的值。三个条件各有原因：$M>0$ 是因为 $a^p$ 总是正数；$a\ne1$ 是因为 $1^p$ 恒为 $1$，无法确定 $p$；$a>0$ 是因为指数函数只对正底定义。

补充例题　由定义求未知量原创

求值：(1) $\log_{\sqrt2}8$；(2) 满足 $\log_x 27=\dfrac32$ 的 $x$；(3) 满足 $\log_{\frac13}M=-2$ 的 $M$。(4) 求使 $\log_{x-1}(5-x)$ 有意义的 $x$ 的范围。

  1. (1) 设其值为 $p$，则 $(\sqrt2)^p=8$，即 $2^{\frac{p}{2}}=2^3$，所以 $\dfrac{p}{2}=3$，$p=6$。
  2. (2) 改写为指数式：$x^{\frac32}=27$。两边取 $\dfrac23$ 次方：$x=27^{\frac23}=(3^3)^{\frac23}=9$，满足 $x>0,\ x\ne1$。
  3. (3) 改写为指数式：$M=\left(\dfrac13\right)^{-2}=3^2=9$。
  4. (4) 底的条件：$x-1>0$ 且 $x-1\ne1$，即 $x>1$ 且 $x\ne2$。
  5. (4) 真数条件：$5-x>0$，即 $x<5$。合并得 $1<x<5$ 且 $x\ne2$。

答案：(1) $6$；(2) $x=9$；(3) $M=9$；(4) $1<x<2$ 或 $2<x<5$。

常见错误：

  • 以为对数值必须为正。$\log_a M$ 可以是负数或 $0$（如 $\log_3\dfrac19=-2$），必须为正的是真数。
  • 底含未知数时，只写 $x-1>0$，漏掉 $x-1\ne1$。
  • 把 $a^p=M$ 改写成 $\log_M a=p$，弄反了底和真数。

EJU 应试提示：对数式不好处理时，先改写成指数式（指数の形に直す）。题目出现含 $x$ 的底或真数，第一行就写条件；答案常要排除个别值，这一步很容易失分。

日语术语：対数（たいすう）：对数；真数（しんすう）：真数；真数条件（しんすうじょうけん）：真数大于 0 的条件；底の条件（ていのじょうけん）：底的条件。

3.1 基本性质

设 $a,c$ 是不等于 $1$ 的正数，$M,N,b>0$，$r$ 为实数：

$$\log_a 1=0,\quad \log_a a=1$$
$$a^{\log_a M}=M$$
$$\log_a MN=\log_a M+\log_a N$$
$$\log_a\frac{M}{N}=\log_a M-\log_a N$$
$$\log_a M^r=r\log_a M$$
$$\log_a\frac1N=-\log_a N$$

例如 $\log_2 12-\log_2 3=\log_2 4=2$，$\log_6 4+\log_6 9=\log_6 36=2$。

易错：$\log_a(M+N)\ne\log_a M+\log_a N$；$(\log_a M)^2\ne\log_a M^2=2\log_a M$（后者要求 $M>0$）。

为什么成立：每条性质都是指数律的“翻译”。令 $p=\log_a M$，$q=\log_a N$，即 $a^p=M$，$a^q=N$。于是 $MN=a^{p+q}$，由定义 $\log_a MN=p+q$，这就是积的公式；$\dfrac{M}{N}=a^{p-q}$ 给出商的公式；$M^r=a^{pr}$ 给出 $\log_a M^r=r\log_a M$。$a^{\log_a M}=M$ 只是把定义代回去：$\log_a M$ 正是“$a$ 要取的指数”。

补充例题　对数运算与用字母表示原创

(1) 计算 $\log_{10}25+2\log_{10}2$。(2) 计算 $\log_3 18-2\log_3\sqrt2$。(3) 计算 $4^{\log_2 3}$。(4) 设 $\log_{10}2=a$，$\log_{10}3=b$，用 $a,b$ 表示 $\log_{10}45$。

  1. (1) 系数移到真数的指数上：$2\log_{10}2=\log_{10}4$。合并：$\log_{10}(25\times4)=\log_{10}100=2$。
  2. (2) $2\log_3\sqrt2=\log_3(\sqrt2)^2=\log_3 2$。所以原式 $=\log_3\dfrac{18}{2}=\log_3 9=2$。
  3. (3) 化成 $a^{\log_a M}$ 的形式：$4^{\log_2 3}=(2^2)^{\log_2 3}=\left(2^{\log_2 3}\right)^2=3^2=9$。
  4. (4) 分解：$45=9\times5=3^2\times\dfrac{10}{2}$。
  5. (4) 所以 $\log_{10}45=2\log_{10}3+\log_{10}10-\log_{10}2=2b+1-a$。

答案：(1) $2$；(2) $2$；(3) $9$；(4) $2b+1-a$。

常见错误：

  • $\dfrac{\log_a M}{\log_a N}$ 与 $\log_a\dfrac{M}{N}$ 混淆。商的公式说的是真数相除，对数相除要用换底公式。
  • $\log_a M^2=2\log_a M$ 只在 $M>0$ 时直接成立；若 $M$ 可能为负，应写 $\log_a M^2=2\log_a|M|$。
  • 认为 $\log_{10}5$ 无法用 $\log_{10}2$ 表示。其实 $5=\dfrac{10}{2}$，这是最常用的一步。

EJU 应试提示：计算时把系数“收进”真数，合并后常得到整数；表示题则相反，把真数“拆开”成已知的质因数。含 $5$ 时就用 $\log_{10}5=1-\log_{10}2$。

日语术语：真数（しんすう）：真数；素因数分解（そいんすうぶんかい）：质因数分解；積（せき）：积；商（しょう）：商。

3.2 换底公式（底の変換公式）

底不相同时，先换成同一个底（$b>0$，$c>0,\ c\ne1$）：

$$\log_a b=\frac{\log_c b}{\log_c a}$$

由此得到两个常用推论（$b\ne1$，$k\ne0$）：

$$\log_a b\cdot\log_b a=1$$
$$\log_{a^k}b^m=\frac{m}{k}\log_a b$$

例如 $\log_4 8=\dfrac{\log_2 8}{\log_2 4}=\dfrac32$，$\log_8 32=\dfrac53$。

为什么成立：令 $p=\log_a b$，即 $a^p=b$。两边取以 $c$ 为底的对数：$p\log_c a=\log_c b$。因为 $a\ne1$，$\log_c a\ne0$，可以相除，得 $p=\dfrac{\log_c b}{\log_c a}$。在公式中取 $c=b$（要求 $b\ne1$），得 $\log_a b=\dfrac{1}{\log_b a}$，这就是第一个推论。第二个推论：$\log_{a^k}b^m=\dfrac{\log_c b^m}{\log_c a^k}=\dfrac{m\log_c b}{k\log_c a}=\dfrac{m}{k}\log_a b$。

补充例题　连乘、和的积与字母表示原创

(1) 计算 $\log_2 3\cdot\log_3 5\cdot\log_5 8$。(2) 计算 $(\log_2 9+\log_4 3)(\log_3 2+\log_9 2)$。(3) 设 $\log_2 3=a$，用 $a$ 表示 $\log_{12}18$。

  1. (1) 全部换成常用对数相约：$\dfrac{\log_{10}3}{\log_{10}2}\cdot\dfrac{\log_{10}5}{\log_{10}3}\cdot\dfrac{\log_{10}8}{\log_{10}5}=\dfrac{\log_{10}8}{\log_{10}2}=\log_2 8=3$。
  2. (2) 第一个括号换成底 $2$：记 $L=\log_2 3$，则 $\log_2 9=2L$，$\log_4 3=\dfrac12L$，和为 $\dfrac52L$。
  3. (2) 第二个括号：$\log_3 2=\dfrac1L$，$\log_9 2=\dfrac12\cdot\dfrac1L$，和为 $\dfrac{3}{2L}$。
  4. (2) 相乘，$L$ 约去：$\dfrac52L\cdot\dfrac{3}{2L}=\dfrac{15}{4}$。
  5. (3) 换成底 $2$：$\log_{12}18=\dfrac{\log_2 18}{\log_2 12}$。
  6. (3) 分解：$\log_2 18=\log_2(2\cdot3^2)=1+2a$，$\log_2 12=\log_2(2^2\cdot3)=2+a$，所以结果为 $\dfrac{1+2a}{2+a}$。

答案：(1) $3$；(2) $\dfrac{15}{4}$；(3) $\dfrac{1+2a}{2+a}$。

常见错误：

  • $\log_{a^k}b^m$ 写成 $\dfrac{k}{m}\log_a b$，把比值颠倒。记法：真数的指数在上，底的指数在下，如 $\log_8 32=\log_{2^3}2^5=\dfrac53$。
  • 把 $\log_a b\cdot\log_b c$ 算成 $\log_a b+\log_b c$，或错写成 $\log_a(bc)$；正确结果是 $\log_a c$。
  • 换底时分子分母放反：所求对数的真数在分子，底在分母。

EJU 应试提示：一题中出现多个不同的底时，不要逐项求值，应立刻换成同一个最小的底（如 $4,8,16$ 换成 $2$），并把共同的对数记为一个字母，算式会短很多。

日语术语：底の変換公式（ていのへんかんこうしき）：换底公式；常用対数（じょうようたいすう）：常用对数；逆数（ぎゃくすう）：倒数。

补充例题　求反函数与复合真数的值域原创

(1) 求 $y=2^{x-1}+3$ 的反函数及其定义域。(2) 求 $y=\log_3(x^2-4x+13)$ 的定义域和最小值。

  1. (1) 原函数的值域是 $y>3$，这就是反函数的定义域。
  2. (1) 用 $y$ 表示 $x$：$y-3=2^{x-1}$，取对数得 $x-1=\log_2(y-3)$，$x=\log_2(y-3)+1$。
  3. (1) 交换 $x,y$：$y=\log_2(x-3)+1$（$x>3$）。检验：原函数过 $(5,19)$，而 $\log_2(19-3)+1=5$，反函数过 $(19,5)$。
  4. (2) 配方：$x^2-4x+13=(x-2)^2+9\ge9>0$，真数恒正，定义域为全体实数。
  5. (2) 底 $3>1$，真数最小时函数值最小。真数最小值是 $9$（$x=2$），所以 $y$ 的最小值为 $\log_3 9=2$。

答案：(1) $y=\log_2(x-3)+1\ (x>3)$；(2) 定义域为全体实数，最小值 $2$（$x=2$）。

常见错误：

  • 求反函数时漏写定义域。定义域要从原函数的值域得到，不能只看最后的式子。
  • 把 $\log_2 x$ 与 $\log_{\frac12}x$ 的对称关系记成“关于 $y$ 轴对称”。正确的是关于 $x$ 轴对称，因为 $\log_{\frac12}x=-\log_2 x$。
  • 复合函数直接把二次式的顶点当答案，忘记再取一次对数；或底小于 $1$ 时仍认为真数最小对应函数值最小。

EJU 应试提示：对数函数的最值分两层思考：先求真数的范围，再按底的大小判断单调方向。底小于 $1$ 时，真数最小对应函数值最大。

补充例题　对称点的计算原创

曲线 $y=a^x$（$a>0,\ a\ne1$）过点 $\mathrm{P}(2,9)$。(1) 求 $a$。(2) 求 P 关于 $y=x$ 的对称点 Q，并验证它在 $y=\log_a x$ 上。(3) 求线段 PQ 的长度、中点和斜率。

  1. (1) 代入：$a^2=9$。由 $a>0$ 得 $a=3$，负根 $a=-3$ 舍去。
  2. (2) 坐标互换：$\mathrm{Q}(9,2)$。验证：$\log_3 9=2$，在曲线上。
  3. (3) 长度：$\mathrm{PQ}=\sqrt{(9-2)^2+(2-9)^2}=\sqrt{98}=7\sqrt2$。
  4. (3) 中点：$\left(\dfrac{2+9}{2},\dfrac{9+2}{2}\right)=\left(\dfrac{11}{2},\dfrac{11}{2}\right)$，确实在 $y=x$ 上。
  5. (3) 斜率：$\dfrac{2-9}{9-2}=-1$，与 $y=x$ 垂直。

  • 由 $a^2=9$ 写出 $a=\pm3$，忘记底必须为正。

  • 把“关于 $y=x$ 对称”与“关于 $y=-x$ 对称”弄混。前者是 $(p,q)\to(q,p)$，后者是 $(p,q)\to(-q,-p)$。

EJU 应试提示：题目给出指数曲线上的点、要求对数曲线上的点时，直接交换坐标，不必重新代入计算。需要作图判断交点个数时，$a>1$ 与 $0<a<1$ 要分别考虑。

4.1 对数方程与不等式

固定流程：① 写真数条件（和底的条件）→ ② 化成同底 → ③ 去掉 $\log$ 解题 → ④ 用条件筛选。

  • 方程：$\log_2(x+1)=3\Rightarrow x+1=2^3\Rightarrow x=7$。
  • $a>1$，方向不变：$\log_3 x<2\Rightarrow 0<x<9$。
  • $0<a<1$，方向反转：$\log_{\frac13}x<2\Rightarrow x>\dfrac19$。

易错：$0<x<9$ 中的“$0<x$”来自真数条件，漏写就错。合并对数后真数条件会放宽，所以必须在合并之前写好条件，否则容易留下增根。

为什么成立：对数函数单调，所以 $\log_a X=\log_a Y\iff X=Y$（$X,Y>0$），这就是可以去掉 $\log$ 的依据。不等式的方向同样由单调性决定。至于为什么要先写条件：$\log_2(x-2)+\log_2(x+5)$ 要求两个真数都为正，而合并后的 $\log_2(x-2)(x+5)$ 只要求乘积为正，$x=-6$ 就满足后者而不满足前者。变形扩大了取值范围，增根就是这样产生的。

补充例题　不同底的对数方程与不等式原创

(1) 解方程 $\log_2(x+2)=\log_4(x+8)$。(2) 解不等式 $\log_{\frac13}(x-1)>\log_{\frac19}(x+5)$。

  1. (1) 真数条件：$x+2>0$ 且 $x+8>0$，即 $x>-2$。
  2. (1) 化同底：$\log_4(x+8)=\dfrac12\log_2(x+8)$。两边乘 $2$：$2\log_2(x+2)=\log_2(x+8)$，即 $\log_2(x+2)^2=\log_2(x+8)$。
  3. (1) 去掉 $\log$：$(x+2)^2=x+8$，整理得 $x^2+3x-4=0$，$(x+4)(x-1)=0$。
  4. (1) $x=-4$ 不满足 $x>-2$，舍去，所以 $x=1$。检验：$\log_2 3=\log_4 9$，成立。
  5. (2) 真数条件：$x-1>0$ 且 $x+5>0$，即 $x>1$。
  6. (2) 化同底：$\log_{\frac19}(x+5)=\dfrac12\log_{\frac13}(x+5)$。两边乘 $2$（正数，方向不变）：$\log_{\frac13}(x-1)^2>\log_{\frac13}(x+5)$。
  7. (2) 底 $\dfrac13<1$，去掉 $\log$ 时反向：$(x-1)^2<x+5$，即 $x^2-3x-4<0$，$(x+1)(x-4)<0$，$-1<x<4$。
  8. (2) 与 $x>1$ 合并：$1<x<4$。

答案：(1) $x=1$；(2) $1<x<4$。

常见错误：

  • 先合并后写条件，留下增根（上题 $x=-4$）。
  • 把 $\log_4(x+8)$ 直接当成 $\log_2(x+8)$ 计算，没有处理不同的底。
  • 不等式只解了“去掉 $\log$”之后的部分，忘记与真数条件取交集；或底小于 $1$ 时漏掉反向。
  • 底是字母 $a$ 时没有分类。必须分 $a>1$ 和 $0<a<1$ 两种情况讨论。

EJU 应试提示：填空题的格式也能帮你检查：若题目只留一个答案位，而你解出两个根，多半有一个要由真数条件舍去。答题前把解代回原式看真数是否为正，只需几秒。

日语术语：対数方程式（たいすうほうていしき）：对数方程；対数不等式（たいすうふとうしき）：对数不等式；真数条件（しんすうじょうけん）：真数大于 0 的条件。

4.2 大小比较

化成同底后比较真数。例如比较 $\log_2 3$ 与 $\log_4 8$：$\log_4 8=\dfrac32=\log_2 2^{\frac32}=\log_2\sqrt8$。因为 $\sqrt8<3$ 且底 $2>1$，所以 $\log_4 8<\log_2 3$。

为什么成立：底相同且大于 $1$ 时，对数随真数增大而增大，所以比较对数就是比较真数。根号不同时，取公倍数次方：$0<X<Y\iff X^n<Y^n$（$n$ 为正整数）。若底不能统一，就找一个中间值 $c$，分别证明 $A<c$、$c<B$，从而 $A<B$。

补充例题　同底比较与中间值原创

(1) 将 $\log_2 3,\ \log_4 5,\ \log_8 15$ 按从小到大排列。(2) 比较 $\log_2 3$ 与 $\log_3 5$。

  1. (1) 全部换成底 $2$：$\log_4 5=\dfrac12\log_2 5=\log_2\sqrt5$，$\log_8 15=\dfrac13\log_2 15=\log_2\sqrt[3]{15}$。
  2. (1) 比较真数 $3,\ \sqrt5,\ \sqrt[3]{15}$，都取 $6$ 次方：$3^6=729$，$(\sqrt5)^6=125$，$(\sqrt[3]{15})^6=225$。
  3. (1) 所以 $\sqrt5<\sqrt[3]{15}<3$。底 $2>1$，顺序不变。
  4. (2) 两个底不同且无法化简，取中间值 $\dfrac32$。
  5. (2) $\dfrac32=\log_2 2^{\frac32}=\log_2\sqrt8$，而 $\sqrt8<\sqrt9=3$，所以 $\log_2 3>\dfrac32$。
  6. (2) $\dfrac32=\log_3 3^{\frac32}=\log_3\sqrt{27}$，而 $\sqrt{27}>\sqrt{25}=5$，所以 $\log_3 5<\dfrac32$。
  7. (2) 因此 $\log_3 5<\dfrac32<\log_2 3$。

答案：(1) $\log_4 5<\log_8 15<\log_2 3$；(2) $\log_3 5<\log_2 3$。

常见错误：

  • 只看真数大小，认为 $\log_8 15>\log_2 3$。底不同时真数大小不能直接比较。
  • 底小于 $1$ 时仍按“真数大，对数大”判断。
  • 比较根式时用估算代替严格计算，遇到接近的数容易出错；取公倍数次方更可靠。

EJU 应试提示：中间值怎么选？先粗略估计两个对数：$2^1<3<2^2$，$3^1<5<3^2$，都在 $1$ 与 $2$ 之间，于是试 $\dfrac32$。$0,\ 1,\ \dfrac12,\ \dfrac32$ 是最常用的中间值。

日语术语：大小比較（だいしょうひかく）：大小比较；底をそろえる（ていをそろえる）：化成同底。

4.3 双变量的对数条件：换成 $X,Y$ 看图形

条件中同时出现 $\log_a x$ 与 $\log_a y$ 时，令 $X=\log_a x$，$Y=\log_a y$。$x,y>0$ 时 $X,Y$ 可取任意实数，条件就变成 $XY$ 平面上的直线、圆或区域。要求的量也随之转换：

  • 乘积：$xy=a^{X+Y}$，求 $xy$ 的范围 $\iff$ 求 $X+Y$ 的范围（直线 $X+Y=k$ 与图形有公共点的条件）；
  • 比值：$\dfrac yx=a^{Y-X}$，或直接令 $t=\dfrac yx$ 化为 $t$ 的不等式；
  • $\log_a x\cdot\log_a y=XY$：$X+Y$ 一定时用配方求最值；联立方程“有正实数解”$\iff$ $X,Y$ 为实数（判别式 $\ge0$），若还要求 $x,y>1$，则要 $X,Y>0$。

日语术语：正の実数解（せいのじっすうかい）：正实数解；積（せき）：乘积；比（ひ）：比。

5 常用对数

常用対数 — 桁数・最高位の数字

以 $10$ 为底的对数 $\log_{10}N$ 叫常用对数（常用対数）。考题通常给出 $\log_{10}2=0.3010$、$\log_{10}3=0.4771$；其余数值可由它们推出，如 $\log_{10}5=1-\log_{10}2=0.6990$。

为什么成立：我们用十进制，而任何正数都能写成 $N=b\times10^m$（$1\le b<10$，$m$ 为整数），于是 $\log_{10}N=m+\log_{10}b$，其中 $0\le\log_{10}b<1$。可见整数部分 $m$ 决定数的大小范围（位数），小数部分决定有效数字，后面三节都由此而来。$\log_{10}5$ 能由 $\log_{10}2$ 推出，是因为 $2\times5=10$；$\log_{10}7$ 不能由 $2,3$ 推出，通常要由题目给出。

补充例题　由已知值推算原创

已知 $\log_{10}2=0.3010$，$\log_{10}3=0.4771$。求 $\log_{10}72$、$\log_{10}0.06$、$\log_{10}\sqrt{15}$ 和 $\log_2 3$ 的近似值。

  1. $72=2^3\cdot3^2$：$\log_{10}72=3\times0.3010+2\times0.4771=0.9030+0.9542=1.8572$。
  2. $0.06=\dfrac{2\cdot3}{10^2}$：$\log_{10}0.06=0.3010+0.4771-2=-1.2219$。
  3. $15=\dfrac{3\cdot10}{2}$：$\log_{10}15=0.4771+1-0.3010=1.1761$，所以 $\log_{10}\sqrt{15}=\dfrac12\times1.1761=0.58805$。
  4. 换底：$\log_2 3=\dfrac{\log_{10}3}{\log_{10}2}=\dfrac{0.4771}{0.3010}\approx1.585$。

答案：$1.8572$；$-1.2219$；$0.58805$；约 $1.585$。

常见错误：

  • 把 $\log_{10}0.06$ 当成正数。真数小于 $1$ 时常用对数为负。
  • 把 $\log_{10}5$ 算成 $\dfrac{\log_{10}10}{\log_{10}2}$。应为差：$\log_{10}5=\log_{10}10-\log_{10}2$。
  • 对“$0.3010+0.4771=0.7781$，而表中 $\log_{10}6=0.7782$”感到困惑。真值约 $0.77815$，表中是四舍五入，两者的差只是近似误差。考试中用题目给定的值计算。

EJU 应试提示：先把真数分解成 $2,3,5,10$ 的积，再代入数值。题目给出哪些近似值就只用哪些，不必背对数表。

日语术语：常用対数（じょうようたいすう）：常用对数；近似値（きんじち）：近似值；四捨五入（ししゃごにゅう）：四舍五入；整数部分（せいすうぶぶん）：整数部分；小数部分（しょうすうぶぶん）：小数部分。

5.1 求位数（桁数）

$N$ 的整数部分是 $n$ 位数时：

$$10^{n-1}\le N<10^n\iff n-1\le\log_{10}N<n$$

例：$\log_{10}2^{100}=100\times0.3010=30.10$，所以 $30\le\log_{10}2^{100}<31$，$2^{100}$ 是 $31$ 位数。

为什么成立：$n$ 位数中最小的是 $10^{n-1}$（$1$ 后面 $n-1$ 个 $0$），最大的也小于 $10^n$，所以 $10^{n-1}\le N<10^n$。$y=\log_{10}x$ 递增，取对数后方向不变。左边带等号：$\log_{10}N$ 恰为整数 $n-1$ 时，$N=10^{n-1}$ 仍是 $n$ 位数。结论可以简记为：位数 = $\log_{10}N$ 的整数部分 + $1$（$N\ge1$）。

补充例题　求位数及其逆问题原创

已知 $\log_{10}2=0.3010$，$\log_{10}3=0.4771$。(1) $12^{30}$ 是几位数？(2) 使 $2^n$ 为 $10$ 位数的正整数 $n$ 有哪些？

  1. (1) $\log_{10}12=2\log_{10}2+\log_{10}3=0.6020+0.4771=1.0791$。
  2. (1) $\log_{10}12^{30}=30\times1.0791=32.373$，即 $32\le\log_{10}12^{30}<33$，所以是 $33$ 位数。
  3. (2) $10$ 位数的条件：$10^9\le2^n<10^{10}$。取常用对数：$9\le0.3010\,n<10$。
  4. (2) 除以 $0.3010$：$29.9\cdots\le n<33.2\cdots$，所以 $n=30,31,32,33$。
  5. (2) 验算：$2^{30}=1073741824$，$2^{33}=8589934592$，都是 $10$ 位；$2^{29}=536870912$ 只有 $9$ 位。

答案：(1) $33$ 位；(2) $n=30,31,32,33$。

常见错误：

  • 把位数直接写成 $\log_{10}N$ 的整数部分，忘记加 $1$。$2^{100}$ 的对数是 $30.10$，是 $31$ 位而不是 $30$ 位。
  • 四舍五入：把 $32.373$ 或 $30.9$ 的整数部分取错。无论小数部分多大，都只取整数部分。
  • 不等式写成 $10^n\le N<10^{n+1}$，却仍把 $n$ 当位数；此时位数应为 $n+1$。

EJU 应试提示：先写 $\log_{10}N=$ 整数 $+$ 小数，再回答位数。日语题干常写 $2^{100}$ は何桁の数か（$2^{100}$ 是几位数）。逆问题要注意端点是否取得到。

日语术语：桁数（けたすう）：位数；何桁（なんけた）：几位；以上（いじょう）：大于等于；未満（みまん）：小于。

5.2 求小数首个非零数字的位置

$0<N<1$，且小数第 $n$ 位首次出现非零数字时：

$$10^{-n}\le N<10^{-n+1}\iff -n\le\log_{10}N<-n+1$$

例：$\log_{10}0.2^{10}=10(0.3010-1)=-6.990$，所以 $-7\le\log_{10}0.2^{10}<-6$，首个非零数字在小数第 $7$ 位。注意 $-6.990$ 向下取整是 $-7$，不是 $-6$。

为什么成立：小数第 $n$ 位首次出现非零数字，说明 $N$ 不小于 $0.0\cdots01$（$1$ 在第 $n$ 位，即 $10^{-n}$），又小于 $0.0\cdots1$（$1$ 在第 $n-1$ 位，即 $10^{-n+1}$）。例如 $0.0034$ 首个非零数字在第 $3$ 位，确实有 $10^{-3}\le0.0034<10^{-2}$。结论：$n$ 等于 $-\log_{10}N$ 向上取整；也可以把 $\log_{10}N$ 写成 $-n+q$（$0\le q<1$）后直接读出 $n$。

补充例题　小数首个非零数字的位置原创

已知 $\log_{10}2=0.3010$，$\log_{10}3=0.4771$。$\left(\dfrac23\right)^{50}$ 写成小数时，首个非零数字出现在小数第几位？

  1. $\log_{10}\dfrac23=0.3010-0.4771=-0.1761$。
  2. $\log_{10}\left(\dfrac23\right)^{50}=50\times(-0.1761)=-8.805$。
  3. 夹在相邻整数之间：$-9\le-8.805<-8$，即 $10^{-9}\le\left(\dfrac23\right)^{50}<10^{-8}$。
  4. 对照公式，$n=9$。（精确计算约为 $1.57\times10^{-9}$，一致。）

答案：小数第 $9$ 位。

常见错误：

  • 把 $-8.805$ 的整数部分当成 $-8$，答成第 $8$ 位。小数部分必须非负，所以应写成 $-9+0.195$。
  • 位数公式照搬到小数上，算成第 $9+1=10$ 位。小数的情形没有“加 $1$”。
  • 把 $\log_{10}0.8$ 等算成正数，导致不等号方向错误。

EJU 应试提示：用小例子校准：$0.01=10^{-2}$，对数是 $-2$，首个非零数字在第 $2$ 位。考场上不确定公式时，这样验证一下最快。

日语术语：小数第n位（しょうすうだいエヌい）：小数第 n 位；はじめて（はじめて）：首次（はじめて 0 でない数字が現れる：首次出现非零数字）。

5.3 求最高位数字

把 $\log_{10}N$ 写成“整数 + 小数部分 $q$”（$0\le q<1$），若 $\log_{10}k\le q<\log_{10}(k+1)$，则最高位数字（最高位の数字）是 $k$。

例：$\log_{10}5^{20}=20\times0.6990=13.98$，$5^{20}$ 是 $14$ 位数。由 $\log_{10}9=0.9542\le0.98<1$，最高位数字是 $9$。

为什么成立：设 $\log_{10}N=m+q$（$m$ 为整数，$0\le q<1$），则 $N=10^q\times10^m$，其中 $1\le10^q<10$。最高位数字就是 $10^q$ 的整数部分 $k$，即 $k\le10^q<k+1$。取对数，就得到 $\log_{10}k\le q<\log_{10}(k+1)$。小数部分同样适用，只是此时 $m$ 为负，读出的 $k$ 是首个非零数字。

补充例题　最高位与个位原创

已知 $\log_{10}3=0.4771$，$\log_{10}2=0.3010$，$\log_{10}7=0.8451$。求 $3^{50}$ 的位数、最高位数字和个位数字。

  1. $\log_{10}3^{50}=50\times0.4771=23.855$，整数部分 $23$，所以是 $24$ 位数。
  2. 小数部分 $q=0.855$。需要 $\log_{10}7=0.8451$ 和 $\log_{10}8=3\times0.3010=0.9030$。
  3. 因为 $0.8451\le0.855<0.9030$，所以最高位数字是 $7$。
  4. 个位数字另用周期性：$3,9,27,81,243,\cdots$ 的个位按 $3,9,7,1$ 循环，周期为 $4$。
  5. $50=4\times12+2$，对应循环的第 $2$ 个，个位数字是 $9$。
  6. 验算：$3^{50}=717897987691852588770249$，$24$ 位，首位 $7$，末位 $9$。

答案：$24$ 位；最高位数字 $7$；个位数字 $9$。

常见错误：

  • 把 $k$ 取成 $10^q$ 四舍五入后的值。$k$ 是向下取整，$10^q\approx7.16$ 时取 $7$；即使是 $7.9$ 也取 $7$。
  • 用整数部分而不是小数部分去查表。
  • 想用对数求个位数字。对数只反映大小和前几位，不能给出个位；个位要用幂的周期性。

EJU 应试提示：题目常把“位数、最高位、个位”放在同一题。若题目给了 $\log_{10}7$ 的值，往往意味着 $q$ 落在 $7$ 附近；若没给，也可以由 $2,3$ 算出 $4,5,6,8,9$ 的对数作比较。

日语术语：最高位の数字（さいこういのすうじ）：最高位数字；一の位（いちのくらい）：个位；周期（しゅうき）：周期。

互动：位数计算器

怎样使用这个演示：先用下面的步骤手算，再把滑块调到相同的 $a,n$ 核对。计算器用精确整数给出结果，可以用来发现自己的手算错误；$a=10$ 时试试看位数比指数多几。

为什么成立：计算器的第一行是 $\log_{10}a^n=n\log_{10}a$，这正是把乘方变成乘法。$a^n$ 再大，其对数也只是一个不大的数，这就是对数能处理大数的原因。

补充例题　手算后用计算器核对原创

已知 $\log_{10}2=0.3010$，$\log_{10}3=0.4771$。(1) 求 $15^{40}$ 的位数和最高位数字。(2) $10^5$ 是几位数？

  1. (1) $\log_{10}15=\log_{10}3+\log_{10}5=0.4771+0.6990=1.1761$。
  2. (1) $\log_{10}15^{40}=40\times1.1761=47.044$，整数部分 $47$，所以是 $48$ 位数。
  3. (1) 小数部分 $0.044$，满足 $0\le0.044<0.3010$，即落在 $\log_{10}1$ 与 $\log_{10}2$ 之间，最高位数字是 $1$。
  4. (1) 把滑块调到 $a=15,\ n=40$，显示 $48$ 位、最高位 $1$，一致。
  5. (2) $\log_{10}10^5=5$，恰为整数。因为 $5\le5<6$（左边取等号），所以是 $6$ 位数，即 $100000$。

答案：(1) $48$ 位，最高位 $1$；(2) $6$ 位。

常见错误：

  • 对数恰为整数时答错位数，$\log_{10}N=5$ 也是 $6$ 位。
  • 认为近似值总能算准。指数 $n$ 很大时，$\log_{10}2$ 的微小误差也被放大 $n$ 倍，若小数部分恰好靠近边界，结论就可能不可靠。
  • 把计算器当作算法本身。考试时不能使用计算器，手算步骤必须熟练。

EJU 应试提示：平时用此工具做反向练习：随手选 $a,n$，先写出位数和最高位的预测，再看结果。这比只看答案更能暴露步骤上的错误。

日语术语：計算（けいさん）：计算；確かめる（たしかめる）：验算、确认。

5.4 应用：反复变化的量

“每次变为原来的 $r$ 倍，几次后超过（或低于）某值”这类题，两边取常用对数即可。若 $\log_{10}r<0$，两边同除以它时不等号要反向。

为什么成立：每次变为 $r$ 倍，$n$ 次后就是初值的 $r^n$ 倍。对 $r^n>c$（$c>0$）两边取常用对数，$y=\log_{10}x$ 递增，方向不变，得 $n\log_{10}r>\log_{10}c$。接下来要除以 $\log_{10}r$：$r>1$ 时它为正，方向不变；$0<r<1$ 时它为负，方向反转。所以“取对数”本身不反向，反向发生在除以负数那一步。

补充例题　增长与衰减原创

已知 $\log_{10}2=0.3010$，$\log_{10}3=0.4771$。(1) 某量每年增加 $8\%$，至少多少年后超过原来的 $2$ 倍？(2) 某量每次减少 $10\%$，至少多少次后低于原来的一半？

  1. (1) 每年变为 $1.08$ 倍，设 $n$ 年后超过 $2$ 倍：$1.08^n>2$。
  2. (1) 计算 $\log_{10}1.08=\log_{10}\dfrac{108}{100}=2\log_{10}2+3\log_{10}3-2=0.6020+1.4313-2=0.0333$。
  3. (1) 取对数：$0.0333\,n>0.3010$，$n>9.03\cdots$，所以至少 $10$ 年。（验算：$1.08^9\approx1.999$，$1.08^{10}\approx2.159$。）
  4. (2) 每次变为 $0.9$ 倍，设 $n$ 次后低于一半：$0.9^n<\dfrac12$。
  5. (2) 计算 $\log_{10}0.9=2\log_{10}3-1=0.9542-1=-0.0458$，且 $\log_{10}\dfrac12=-0.3010$。
  6. (2) 取对数：$-0.0458\,n<-0.3010$。除以负数，方向反转：$n>6.57\cdots$，所以至少 $7$ 次。（验算：$0.9^6\approx0.531$，$0.9^7\approx0.478$。）

答案：(1) $10$ 年；(2) $7$ 次。

常见错误：

  • 把“增加 $8\%$”写成 $0.08^n$；应为 $(1+0.08)^n$。“减少 $10\%$”应为 $0.9^n$，不是 $0.1^n$。
  • 除以负的 $\log_{10}0.9$ 时忘记反向，得到 $n<6.57\cdots$。
  • 把 $n>9.03\cdots$ 四舍五入成 $9$。题目问“至少”，应取满足不等式的最小整数，即 $10$。

EJU 应试提示：把百分率翻译成倍数是第一步。日语常见说法：8%増加する（增加 $8\%$）、はじめて2倍を超える（首次超过 $2$ 倍）。结果要取整数时，把边界附近的两个整数代回确认最稳妥。

日语术语：倍（ばい）：倍；増加（ぞうか）：增加；減少（げんしょう）：减少；超える（こえる）：超过；少なくとも（すくなくとも）：至少。

6 原创 EJU 风格例题

以下题目均为本讲义原创，仅模仿 EJU 的填空形式，并非真题。

填空规则：每个方框字母对应一个数字（$0$–$9$），例如 $\B{AB}$ 是两位数；分数要约到最简，根号内的数要尽量小。

例题 1　指数函数的最值原创

考虑函数 $y=4^x-2^{x+3}+10\quad(-1\le x\le3)$。令 $t=2^x$。

(1) $t$ 的取值范围是 $\dfrac{1}{\B{A}}\le t\le\B{B}$。

(2) 用 $t$ 表示，$y=t^2-\B{C}\,t+\B{DE}$。

(3) $y$ 在 $x=\B{F}$ 时取最小值 $-\B{G}$，在 $x=\B{H}$ 时取最大值 $\B{IJ}$。

  • A = 2
  • B = 8
  • C = 8
  • DE = 10
  • F = 2
  • G = 6
  • H = 3
  • IJ = 10

(1) $2^x$ 单调递增，所以 $2^{-1}\le t\le2^3$。

(2) $4^x=t^2$，$2^{x+3}=8t$，故 $y=t^2-8t+10$。

补充说明：解题顺序是“换元 → 写范围 → 配方 → 比较”。最大值不必把两端都算出：抛物线开口向上，离对称轴越远函数值越大。$\left|\dfrac12-4\right|=\dfrac72<|8-4|=4$，所以 $t=8$ 一端更大。

(3) $y=(t-4)^2-6$。$t=4$（即 $x=2$）在范围内，最小值为 $-6$。两端比较：$t=\dfrac12$ 时 $y=\dfrac{25}{4}$，$t=8$ 时 $y=10$，所以最大值为 $10$，此时 $x=3$。

例题 2　对数方程与不等式原创

(1) 方程 $\log_2(x-2)+\log_2(x+5)=3$ 的真数条件为 $x>\B{A}$。去掉对数后得 $x^2+\B{B}\,x-\B{CD}=0$，所以解为 $x=\B{E}$。

(2) 不等式 $\log_{\frac12}(x-1)+\log_{\frac12}(x-3)\ge-3$ 的解为 $\B{F}<x\le\B{G}$。

(3) 方程 $(\log_3 x)^2-\log_3 x^4+3=0$ 的解为 $x=\B{H}$ 和 $x=\B{IJ}$。

  • A = 2
  • B = 3
  • CD = 18
  • E = 3
  • F = 3
  • G = 5
  • H = 3
  • IJ = 27

(1) 由 $x-2>0$ 且 $x+5>0$ 得 $x>2$。$(x-2)(x+5)=2^3$，即 $x^2+3x-18=0$，$(x+6)(x-3)=0$。$x=-6$ 不满足条件，舍去，故 $x=3$。

(2) 真数条件为 $x>3$。$-3=\log_{\frac12}8$，底小于 $1$，不等号反向：$(x-1)(x-3)\le8$，即 $(x+1)(x-5)\le0$，$-1\le x\le5$。与条件合并得 $3<x\le5$。

补充说明：(1) 代回检验：$\log_2 1+\log_2 8=0+3=3$。(2) $-3=\log_{\frac12}8$ 是因为 $\left(\dfrac12\right)^{-3}=2^3=8$。(3) 两个解都为正，都满足真数条件；代回检验：$x=3$ 时 $1-4+3=0$，$x=27$ 时 $9-12+3=0$。

(3) 令 $t=\log_3 x$（$x>0$），$\log_3 x^4=4t$，$t^2-4t+3=0$，$t=1,3$，所以 $x=3,27$。

例题 3　常用对数与位数原创

已知 $\log_{10}2=0.3010$，$\log_{10}3=0.4771$。

(1) $6^{30}$ 是 $\B{AB}$ 位数，最高位数字是 $\B{C}$，个位数字是 $\B{D}$。

(2) $\left(\dfrac16\right)^{20}$ 写成小数时，首个非零数字出现在小数第 $\B{EF}$ 位，这个数字是 $\B{G}$。

(3) 满足 $\left(\dfrac32\right)^n>1000$ 的最小正整数 $n$ 是 $\B{HI}$。

  • AB = 24
  • C = 2
  • D = 6
  • EF = 16
  • G = 2
  • HI = 18

(1) $\log_{10}6=0.7781$，$\log_{10}6^{30}=23.343$，所以是 $24$ 位数。由 $0.3010\le0.343<0.4771$ 知最高位是 $2$。$6$ 的任意正整数次幂个位都是 $6$。

(2) $\log_{10}\left(\dfrac16\right)^{20}=-15.562=-16+0.438$，所以在小数第 $16$ 位。由 $0.3010\le0.438<0.4771$ 知这个数字是 $2$。

补充说明：(1) 因为 $23.343=23+0.343$，$6^{30}=10^{0.343}\times10^{23}$，而 $2\le10^{0.343}<3$。(2) 小数部分必须非负，所以把 $-15.562$ 写成 $-16+0.438$，得 $\left(\dfrac16\right)^{20}=10^{0.438}\times10^{-16}$。(3) $\log_{10}\dfrac32=\log_{10}3-\log_{10}2$，$1000$ 的对数是 $3$；$n$ 要取满足不等式的最小整数。

(3) $\log_{10}\dfrac32=0.1761$，由 $0.1761\,n>3$ 得 $n>17.03\cdots$，所以 $n=18$。

例题 4　对称式换元原创

对全体实数 $x$，考虑函数 $y=4^x+4^{-x}-6(2^x+2^{-x})+10$。令 $t=2^x+2^{-x}$。

(1) $t\ge\B{A}$，等号在 $x=\B{B}$ 时成立。

(2) 用 $t$ 表示，$y=t^2-\B{C}\,t+\B{D}$。

(3) $y$ 的最小值为 $-\B{E}$，此时 $t=\B{F}$，$2^x=\dfrac{\B{G}\pm\sqrt{\B{H}}}{\B{I}}$。

  • A = 2
  • B = 0
  • C = 6
  • D = 8
  • E = 1
  • F = 3
  • G = 3
  • H = 5
  • I = 2

(1) $2^x>0,\ 2^{-x}>0$，由算术—几何平均不等式 $t\ge2\sqrt{2^x\cdot2^{-x}}=2$，等号当 $2^x=2^{-x}$ 即 $x=0$ 时成立。

(2) $4^x+4^{-x}=t^2-2$，所以 $y=t^2-2-6t+10=t^2-6t+8$。

补充说明：(2) 由 $(2^x+2^{-x})^2=4^x+2+4^{-x}$ 移项得 $4^x+4^{-x}=t^2-2$。(3) 顶点 $t=3$ 必须落在 $t\ge2$ 内才可取到，这正是 (1) 的作用；否则最小值要改在端点 $t=2$ 取。

(3) $y=(t-3)^2-1$，$t=3\ge2$ 可取到，最小值为 $-1$。令 $s=2^x$，由 $s+\dfrac1s=3$ 得 $s^2-3s+1=0$，$s=\dfrac{3\pm\sqrt5}{2}$，两根都为正，均符合。

EJU 大题常按“换元 → 求范围 → 求最值或解”分步设问，前一问的结果就是后一问的工具。做题时不要跳过前面的小问，它们通常已经给出了解题路线。

补充例题　对数函数之积的最值原创

考虑函数 $y=\log_2\dfrac{x}{2}\cdot\log_2\dfrac{8}{x}\quad(1\le x\le16)$。令 $t=\log_2 x$。

(1) $t$ 的取值范围是 $\B{A}\le t\le\B{B}$。

(2) 用 $t$ 表示，$y=-t^2+\B{C}\,t-\B{D}$。

(3) $y$ 在 $x=\B{E}$ 时取最大值 $\B{F}$，在 $x=\B{G}$ 和 $x=\B{HI}$ 时取最小值 $-\B{J}$。

  • A = 0
  • B = 4
  • C = 4
  • D = 3
  • E = 4
  • F = 1
  • G = 1
  • HI = 16
  • J = 3
  1. (1) 底 $2>1$，$\log_2 x$ 递增：$\log_2 1\le t\le\log_2 16$，即 $0\le t\le4$。
  2. (2) 拆开真数：$\log_2\dfrac{x}{2}=t-1$，$\log_2\dfrac{8}{x}=3-t$。
  3. (2) 相乘：$y=(t-1)(3-t)=-t^2+4t-3$。
  4. (3) 配方：$y=-(t-2)^2+1$。$t=2$ 在范围内，最大值为 $1$；此时 $\log_2 x=2$，$x=4$。
  5. (3) 开口向下，最小值在端点取：$t=0$ 时 $y=-3$，$t=4$ 时 $y=-3$，两端相等（它们到对称轴 $t=2$ 的距离都是 $2$）。
  6. (3) 换回 $x$：$t=0$ 对应 $x=1$，$t=4$ 对应 $x=16$。

答案：最大值 $1$（$x=4$）；最小值 $-3$（$x=1,\ 16$）。

常见错误：

  • 换元后没有把 $x$ 的范围换成 $t$ 的范围，直接在 $x$ 的范围上找顶点。
  • 把 $\log_2\dfrac{x}{2}$ 写成 $\dfrac{t}{2}$；真数的除法对应对数的减法，应为 $t-1$。
  • 答案停在 $t$ 的值上，而题目要填的是 $x$；或把两个端点都取到最小值的情况漏掉一个。

EJU 应试提示：题目中 $\B{A}$、$\B{AB}$ 的格子数是有用的提示：$\B{HI}$ 表示两位数，若你算出一位数，应先回头检查。分数约到最简，根号内的数尽量小，再填写。

日语术语：最大値（さいだいち）：最大值；最小値（さいしょうち）：最小值；平方完成（へいほうかんせい）：配方；とりうる値の範囲（とりうるあたいのはんい）：可取值的范围。

7 练习题

全部原创。常用对数题使用 $\log_{10}2=0.3010$，$\log_{10}3=0.4771$。

题型索引：练习 1–4 指数运算与大小比较（第 1 节）；练习 5–6、16 指数函数、不等式与图像（第 2 节及第 4 节）；练习 7–9 对数运算与换底（第 3 节）；练习 10–12 对数方程、不等式与最值（第 4 节）；练习 13–15 常用对数（第 5 节）。做错的题，先回到对应小节的“常见错误”对照原因，再重做。

练习 1指数运算原创

计算 $27^{\frac23}\times 9^{-\frac12}\div 3^{-2}$。

答案：$27$

化成底 $3$：$3^{2}\times3^{-1}\div3^{-2}=3^{2-1+2}=3^3=27$。

练习 2根式运算原创

化简 $\sqrt[3]{54}-\sqrt[3]{16}+\sqrt[3]{\dfrac14}$。

答案：$\dfrac32\sqrt[3]{2}$

$\sqrt[3]{54}=3\sqrt[3]{2}$，$\sqrt[3]{16}=2\sqrt[3]{2}$，$\sqrt[3]{\dfrac14}=\sqrt[3]{\dfrac{2}{8}}=\dfrac12\sqrt[3]{2}$，合计 $\left(3-2+\dfrac12\right)\sqrt[3]{2}$。

练习 3对称式原创

设 $a>0$，$a^{\frac12}+a^{-\frac12}=3$。求 $a+a^{-1}$ 和 $a^{\frac32}+a^{-\frac32}$。

答案：$7$；$18$

平方：$a+a^{-1}=3^2-2=7$。立方公式：$a^{\frac32}+a^{-\frac32}=3^3-3\cdot3=18$。

练习 4大小比较原创

将 $2^{\frac12},\ 3^{\frac13},\ 5^{\frac15}$ 按从小到大排列。

答案：$5^{\frac15}<2^{\frac12}<3^{\frac13}$

都取 $30$ 次方：$2^{15}=32768$，$3^{10}=59049$，$5^{6}=15625$。$x^{30}$ 在 $x>0$ 时递增，顺序不变。

练习 5指数不等式原创

解不等式 $\left(\dfrac13\right)^{x^2-2x}>\dfrac1{27}$。

答案：$-1<x<3$

$\dfrac1{27}=\left(\dfrac13\right)^3$，底小于 $1$，方向反转：$x^2-2x<3$，即 $(x+1)(x-3)<0$。

练习 6换元解不等式原创

解不等式 $4^x-3\cdot2^{x+1}+8<0$。

答案：$1<x<2$

令 $t=2^x>0$：$t^2-6t+8<0$，$2<t<4$，即 $2^1<2^x<2^2$。

练习 7对数计算原创

计算 $2\log_3 6-\log_3 4$。

答案：$2$

$\log_3 36-\log_3 4=\log_3 9=2$。

练习 8换底公式原创

计算 $\log_2 9\cdot\log_3 8$。

答案：$6$

$\log_2 9=2\log_2 3$，$\log_3 8=3\log_3 2$，且 $\log_2 3\cdot\log_3 2=1$，故积为 $6$。

练习 9用字母表示原创

设 $\log_2 3=a$，$\log_3 5=b$。用 $a,b$ 表示 $\log_6 15$。

答案：$\dfrac{a+ab}{1+a}$

$\log_2 5=\log_2 3\cdot\log_3 5=ab$。换成底 $2$：$\log_6 15=\dfrac{\log_2 3+\log_2 5}{\log_2 2+\log_2 3}=\dfrac{a+ab}{1+a}$。

练习 10真数条件原创

解方程 $2\log_3(x-1)=\log_3(x+5)$。

答案：$x=4$

真数条件 $x>1$。$(x-1)^2=x+5$，$x^2-3x-4=0$，$x=4,-1$。$x=-1$ 不满足条件，舍去。

练习 11底小于 1 的不等式原创

解不等式 $\log_{\frac12}(x-1)>\log_{\frac12}(3-x)$。

答案：$1<x<2$

真数条件 $1<x<3$。底小于 $1$，方向反转：$x-1<3-x$，$x<2$。

练习 12对数函数的最值原创

求 $y=(\log_2 x)^2-\log_2 x^2+3\ \ (1\le x\le8)$ 的最大值、最小值及对应的 $x$。

答案：最大值 $6$（$x=8$）；最小值 $2$（$x=2$）

令 $t=\log_2 x$，$0\le t\le3$，$y=t^2-2t+3=(t-1)^2+2$。$t=1$ 时最小；$t=3$ 时 $y=6$，大于 $t=0$ 时的 $y=3$。

练习 13位数与最高位原创

$3^{40}$ 是几位数？最高位数字是多少？

答案：$20$ 位；最高位是 $1$

$40\times0.4771=19.084$，所以是 $20$ 位数。$0\le0.084<0.3010$，最高位是 $1$。

练习 14小数的位置原创

$(0.3)^{20}$ 写成小数时，首个非零数字出现在小数第几位？这个数字是多少？

答案：第 $11$ 位；数字是 $3$

$20(0.4771-1)=-10.458=-11+0.542$，所以在第 $11$ 位。$0.4771\le0.542<0.6021$，数字是 $3$。

练习 15应用题原创

一层滤网能去除 $20\%$ 的杂质。至少叠加多少层，才能使杂质残留不超过原来的 $1\%$？

答案：$21$ 层

$0.8^n\le0.01$。$\log_{10}0.8=3\times0.3010-1=-0.0970$。$-0.0970\,n\le-2$，方向反转得 $n\ge20.6\cdots$，故至少 $21$ 层。

练习 16图像变换原创

$y=\log_2(2x-4)$ 的图像由 $y=\log_2 x$ 怎样平移得到？求其渐近线。

答案：向右平移 $2$、向上平移 $1$；渐近线 $x=2$

$\log_2(2x-4)=\log_2 2(x-2)=\log_2(x-2)+1$，定义域 $x>2$。

补充例题　方程组与整体处理原创

(1) 解方程组 $\begin{cases}x+y=6\\ \log_2 x+\log_2 y=3\end{cases}$。

(2) 设实数 $x,y$ 满足 $2^x=3^y=12$，求 $\dfrac2x+\dfrac1y$ 的值。

  1. (1) 真数条件：$x>0,\ y>0$。
  2. (1) 第二式合并：$\log_2 xy=3$，所以 $xy=8$。
  3. (1) $x,y$ 是 $t^2-6t+8=0$ 的两根，$(t-2)(t-4)=0$，所以 $(x,y)=(2,4)$ 或 $(4,2)$，都满足条件。
  4. (2) 由定义：$x=\log_2 12$，$y=\log_3 12$。
  5. (2) 用倒数关系：$\dfrac1x=\log_{12}2$，$\dfrac1y=\log_{12}3$。
  6. (2) 所以 $\dfrac2x+\dfrac1y=2\log_{12}2+\log_{12}3=\log_{12}(4\times3)=\log_{12}12=1$。

答案：(1) $(x,y)=(2,4),\ (4,2)$；(2) $1$。

常见错误：

  • $x+y$ 与 $xy$ 已知时只写一组解。除非题目限定大小关系，否则两组都要写。
  • 把 $\log_2 x+\log_2 y$ 写成 $\log_2(x+y)$。
  • 把 $\dfrac1{\log_2 12}$ 算成 $\log_2\dfrac1{12}$。正确的倒数关系是交换底与真数：$\log_{12}2$。

EJU 应试提示：先独立写完再看答案，用时按每题 $3$ 分钟左右练习（这只是练习节奏的建议，并非官方标准）。等式中出现 $2^x=3^y=k$ 时，一律取对数并用倒数关系，不要试图求出 $x,y$ 的近似值。

日语术语：連立方程式（れんりつほうていしき）：方程组；解（かい）：解；解と係数の関係（かいとけいすうのかんけい）：根与系数的关系。

8 日语术语对照表

日语读音中文

EJU 可以选择用日语或英语作答，若选日语，题目中的术语都会以日语出现。对中文使用者而言，真数、底 等汉字词和中文相近，容易掌握；更需要留意的是 以上・以下・未満 这类决定端点是否取等的说法，以及 桁、満たす 等中文里不常见的用字。可在表中搜索中文、日文或假名。

补充例题　读日语题面原创

(1) 不等式 $\log_2(x-1)<3$ を満たす整数 $x$ の個数を求めよ。
(2) $\log_{10}3=0.4771$，$\log_{10}4=0.6021$ とする。$3^{20}$ は何桁の数か。また，最高位の数字を求めよ。

  1. (1) 题意：求满足不等式 $\log_2(x-1)<3$ 的整数 $x$ 的个数（個数）。
  2. (1) 真数条件：$x-1>0$，即 $x>1$。
  3. (1) $3=\log_2 8$，底 $2>1$，方向不变：$x-1<8$，$x<9$。
  4. (1) 所以 $1<x<9$，整数为 $2,3,\cdots,8$，共 $7$ 个。
  5. (2) 题意：$3^{20}$ 是几位数（何桁）？并求最高位数字（最高位の数字）。
  6. (2) $\log_{10}3^{20}=20\times0.4771=9.542$，整数部分 $9$，所以是 $10$ 位数。
  7. (2) 小数部分 $0.542$，满足 $0.4771\le0.542<0.6021$，即 $\log_{10}3\le q<\log_{10}4$，最高位数字是 $3$。（验算：$3^{20}=3486784401$。）

答案：(1) $7$ 个；(2) $10$ 位，最高位数字 $3$。

常见错误：

  • 把 以下 和 未満 混淆：3以下 含 $3$（$x\le3$），3未満 不含 $3$（$x<3$）。
  • 把 個数 当成“求解”，答成 $x$ 的范围。题目要的是数量。
  • 把 底 读成 そこ。数学中读 てい；真数 读 しんすう。

EJU 应试提示：题尾的动词决定答案形式：求めよ（求出）、何桁の数か（几位数）、個数を求めよ（求个数）。先看清要回答什么，再动笔。

日语术语：満たす（みたす）：满足；個数（こすう）：个数；求めよ（もとめよ）：求（题目用语）；以下（いか）：小于等于。

  • 对数运算与换底：用给定的对数 $a,b$ 表示其他对数，关键是统一成同一个底（2006年第2回）。
  • 双变量对数条件化为图形：令 $X=\log x,\ Y=\log y$，把等式化成圆等平面曲线，求 $xy$ 的范围；或把不等式化为比值 $\dfrac yx$ 的二次不等式（2007年第1回、2007年第2回）。见 4.3 节。
  • 含参数方程的解的个数与有解条件：指数方程换元后用“$t>0$ 的部分”数交点（2008年第2回）；联立对数方程有正实数解 $\iff$ 判别式条件（2011年第1回）。见 2.3 节。
  • 与二次方程的根与系数关系结合：二次方程的两根由对数给出，再转回指数方程，求参数的最值（2014年第2回）。

填写方式：每个方框（如 $\boxed{\text{ア}}$）填一位数字或符号 $-$；两个字母相连（如 $\boxed{\text{ウエ}}$）表示两位数。分数约到最简，根号内的数尽量小。同一字母再次出现时填相同的数。

真题风格 1　含 $\sin x$ 的对数式的最值原创 · 对应题型：含 sin x 的对数式的最大值与最小值

设 $0\le x<2\pi$，$f(x)=\log_2(3+\sin x)+\log_2(5-\sin x)$。

(1) 令 $t=\sin x$，则 $-\boxed{\text{ア}}\le t\le\boxed{\text{イ}}$，且 $f(x)=\log_2\bigl\{\boxed{\text{ウエ}}-(t-\boxed{\text{オ}})^2\bigr\}$。

(2) $f(x)$ 在 $x=\dfrac{\pi}{\boxed{\text{キ}}}$ 时取最大值 $\boxed{\text{カ}}$，在 $x=\dfrac{\boxed{\text{コ}}}{\boxed{\text{サ}}}\pi$ 时取最小值 $\boxed{\text{ク}}+\log_2\boxed{\text{ケ}}$。

(3) 满足 $f(x)=\log_2 15$ 的 $x$ 共有 $\boxed{\text{シ}}$ 个。

解答
  1. (1) $-1\le\sin x\le1$。真数 $3+t>0$、$5-t>0$ 恒成立，所以 $f(x)=\log_2(3+t)(5-t)=\log_2(15+2t-t^2)=\log_2\{16-(t-1)^2\}$。
  2. (2) 底 $2>1$，$f$ 随真数增大而增大。$g(t)=16-(t-1)^2$ 在 $-1\le t\le1$ 上递增：$t=1$ 时最大 $16$，$t=-1$ 时最小 $12$。
  3. 最大值 $\log_2 16=4$，此时 $\sin x=1$，$x=\dfrac{\pi}{2}$；最小值 $\log_2 12=2+\log_2 3$，此时 $\sin x=-1$，$x=\dfrac32\pi$。
  4. (3) $16-(t-1)^2=15\iff(t-1)^2=1\iff t=0$ 或 $t=2$。$t=2$ 超出范围舍去；$\sin x=0$ 在 $0\le x<2\pi$ 中有 $x=0,\ \pi$ 两个解。

各格答案：ア = 1，イ = 1，ウエ = 16，オ = 1，カ = 4，キ = 2，ク = 2，ケ = 3，コ = 3，サ = 2，シ = 2

真题风格 2　用已知对数表示其他对数原创 · 对应题型：用已知对数表示目标对数

设 $a=\log_2 3$，$b=\log_3 7$。

(1) $\log_{42}56=\dfrac{ab+\boxed{\text{ア}}}{ab+a+\boxed{\text{イ}}}$。

(2) $\log_{12}63=\dfrac{a\,(b+\boxed{\text{ウ}})}{a+\boxed{\text{エ}}}$。

(3) $\log_6 72=\dfrac{\boxed{\text{オ}}+\boxed{\text{カ}}\,a}{1+a}$。

解答
  1. 统一成底 $2$：$\log_2 7=\log_2 3\cdot\log_3 7=ab$（换底公式）。
  2. (1) $\log_2 56=\log_2(2^3\cdot7)=3+ab$，$\log_2 42=\log_2(2\cdot3\cdot7)=1+a+ab$，所以 $\log_{42}56=\dfrac{ab+3}{ab+a+1}$。
  3. (2) $\log_2 63=\log_2(3^2\cdot7)=2a+ab=a(b+2)$，$\log_2 12=\log_2(2^2\cdot3)=2+a$，所以 $\log_{12}63=\dfrac{a(b+2)}{a+2}$。
  4. (3) $\log_2 72=\log_2(2^3\cdot3^2)=3+2a$，$\log_2 6=1+a$，所以 $\log_6 72=\dfrac{3+2a}{1+a}$。

各格答案：ア = 3，イ = 1，ウ = 2，エ = 2，オ = 3，カ = 2

真题风格 3　对数等式化为圆，求乘积的范围原创 · 对应题型：将对数等式化为平面曲线求乘积范围

正数 $x,y$ 满足 $(\log_2 x)^2+(\log_2 y)^2=\log_2 x^2+\log_2 y^4$。令 $X=\log_2 x$，$Y=\log_2 y$。

(1) 点 $(X,Y)$ 在圆 $(X-\boxed{\text{ア}})^2+(Y-\boxed{\text{イ}})^2=\boxed{\text{ウ}}$ 上。

(2) $X+Y$ 的取值范围是 $\boxed{\text{エ}}-\sqrt{\boxed{\text{オカ}}}\le X+Y\le\boxed{\text{エ}}+\sqrt{\boxed{\text{オカ}}}$。

(3) $xy$ 的最大值是 $2^{\boxed{\text{エ}}+\sqrt{\boxed{\text{オカ}}}}$，此时 $x=2^{\boxed{\text{キ}}+\frac{\sqrt{10}}{\boxed{\text{ク}}}}$。

解答
  1. (1) $\log_2 x^2=2X$，$\log_2 y^4=4Y$，条件为 $X^2+Y^2=2X+4Y$，配方得 $(X-1)^2+(Y-2)^2=5$。$x,y>0$ 时 $X,Y$ 可取任意实数，所以 $(X,Y)$ 取遍整个圆。
  2. (2) 设 $X+Y=k$。直线 $X+Y-k=0$ 与圆有公共点 $\iff$ 圆心 $(1,2)$ 到直线的距离 $\le\sqrt5$：$\dfrac{|3-k|}{\sqrt2}\le\sqrt5$，$|k-3|\le\sqrt{10}$，即 $3-\sqrt{10}\le k\le3+\sqrt{10}$。
  3. (3) $xy=2^{X+Y}$，底 $2>1$，所以 $X+Y$ 最大时 $xy$ 最大，最大值 $2^{3+\sqrt{10}}$。此时切点为圆心沿方向 $\dfrac{1}{\sqrt2}(1,1)$ 移动 $\sqrt5$：$X=1+\sqrt5\cdot\dfrac{1}{\sqrt2}=1+\dfrac{\sqrt{10}}{2}$，故 $x=2^{1+\frac{\sqrt{10}}{2}}$。

各格答案：ア = 1，イ = 2，ウ = 5，エ = 3，オカ = 10，キ = 1，ク = 2

真题风格 4　由对数不等式求比值的范围原创 · 对应题型：由对数不等式求两变量比值范围

正数 $x,y$ 满足 $\log_2 x+\log_2 y\ge2\log_2(x+y)-4$。

(1) 令 $t=\dfrac yx$，条件化为 $t^2-\boxed{\text{アイ}}\,t+1\le0$，所以 $\boxed{\text{ウ}}-\boxed{\text{エ}}\sqrt{\boxed{\text{オ}}}\le\dfrac yx\le\boxed{\text{ウ}}+\boxed{\text{エ}}\sqrt{\boxed{\text{オ}}}$。

(2) 再加上条件 $x+y=8$ 时，$y$ 的最大值为 $\boxed{\text{カ}}+\boxed{\text{キ}}\sqrt{\boxed{\text{ク}}}$。

解答
  1. (1) 两边都是底 $2$：$\log_2 xy\ge\log_2\dfrac{(x+y)^2}{16}$，底 $2>1$，方向不变：$16xy\ge(x+y)^2$。
  2. 两边除以 $x^2>0$，代入 $y=tx$：$16t\ge(1+t)^2$，即 $t^2-14t+1\le0$。两根 $t=7\pm\sqrt{48}=7\pm4\sqrt3$，所以 $7-4\sqrt3\le t\le7+4\sqrt3$。
  3. (2) $x+y=8$ 时 $y=\dfrac{8t}{1+t}=8-\dfrac{8}{1+t}$，随 $t$ 递增。$t=7+4\sqrt3$ 时最大：$y=\dfrac{8(7+4\sqrt3)}{8+4\sqrt3}=\dfrac{2(7+4\sqrt3)}{2+\sqrt3}=2(7+4\sqrt3)(2-\sqrt3)=2(2+\sqrt3)=4+2\sqrt3$。
  4. 检验：此时 $x=4-2\sqrt3>0$，$xy=16-12=4$，$16xy=64=(x+y)^2$，等号成立。

各格答案：アイ = 14，ウ = 7，エ = 4，オ = 3，カ = 4，キ = 2，ク = 3

真题风格 5　含参数指数方程的实数解个数原创 · 对应题型：含参数指数方程的实数解个数

设 $k$ 为实数，考虑关于 $x$ 的方程 $4^x-3\cdot2^{x+1}+k=0$ …①。

(1) 令 $t=2^x$，① 化为 $t^2-\boxed{\text{ア}}\,t+k=0$，其中 $t>0$。函数 $y=t^2-\boxed{\text{ア}}\,t\ (t>0)$ 在 $t=\boxed{\text{ウ}}$ 时取最小值 $-\boxed{\text{イ}}$。

(2) ① 有两个不同实数解的条件是 $\boxed{\text{エ}}<k<\boxed{\text{オ}}$。特别地，$k=8$ 时的解为 $x=\boxed{\text{カ}},\ \boxed{\text{キ}}$（$\boxed{\text{カ}}<\boxed{\text{キ}}$）。

(3) ① 在 $x\ge1$ 的范围内有两个不同实数解的条件是 $\boxed{\text{ク}}\le k<\boxed{\text{ケ}}$。

解答
  1. (1) $4^x=t^2$，$3\cdot2^{x+1}=6t$，得 $t^2-6t+k=0$。$y=t^2-6t=(t-3)^2-9$，最小值 $-9$（$t=3$）。
  2. (2) ① 化为 $-k=t^2-6t$。$t\mapsto x$ 一一对应，所以 $x$ 的解个数 $=$ 抛物线 $y=t^2-6t\ (t>0)$ 与直线 $y=-k$ 的交点个数。抛物线在 $t\to0$ 时趋向 $0$（取不到），最低点 $(3,-9)$。
  3. 两个交点 $\iff-9<-k<0\iff0<k<9$。（$k=9$ 或 $k\le0$ 时一个，$k>9$ 时无解。）
  4. $k=8$：$(t-2)(t-4)=0$，$t=2,4$，$x=1,2$。
  5. (3) $x\ge1\iff t\ge2$。$t=2$ 时 $y=-8$（可以取到）。在 $t\ge2$ 上两个交点 $\iff-9<-k\le-8\iff8\le k<9$。

各格答案：ア = 6，イ = 9，ウ = 3，エ = 0，オ = 9，カ = 1，キ = 2，ク = 8，ケ = 9

真题风格 6　联立对数方程有正实数解的条件原创 · 对应题型：联立对数方程有正实数解的参数范围

设 $a$ 为实数，考虑联立方程 $\log_2(xy)=3$，$\log_2 x\cdot\log_4 y=a$。令 $X=\log_2 x$，$Y=\log_2 y$。

(1) $X+Y=\boxed{\text{ア}}$，$XY=\boxed{\text{イ}}\,a$。

(2) 方程组有正实数解 $(x,y)$ 的条件是 $a\le\dfrac{\boxed{\text{ウ}}}{\boxed{\text{エ}}}$。

(3) 有满足 $x>1,\ y>1$ 的解的条件是 $\boxed{\text{オ}}<a\le\dfrac{\boxed{\text{ウ}}}{\boxed{\text{エ}}}$。

(4) $a=1$ 时，满足 $x<y$ 的解为 $x=\boxed{\text{カ}}$，$y=\boxed{\text{キ}}$。

解答
  1. (1) 真数条件 $x,y>0$。$\log_2 xy=X+Y=3$；$\log_4 y=\dfrac{Y}{2}$，所以 $\dfrac{XY}{2}=a$，$XY=2a$。
  2. (2) $x,y>0$ 与实数 $X,Y$ 一一对应，所以“有正实数解”$\iff$ $X,Y$ 是实数 $\iff$ $u^2-3u+2a=0$ 有实数解 $\iff$ 判别式 $9-8a\ge0\iff a\le\dfrac98$。
  3. (3) $x>1,\ y>1\iff X>0,\ Y>0$。两根都为正：判别式 $\ge0$，和 $3>0$，积 $2a>0$。所以 $0<a\le\dfrac98$。
  4. (4) $a=1$：$u^2-3u+2=0$，$u=1,2$。$x<y$ 即 $X<Y$，$X=1,\ Y=2$，$x=2,\ y=4$。检验：$\log_2 8=3$，$\log_2 2\cdot\log_4 4=1$。

各格答案：ア = 3，イ = 2，ウ = 9，エ = 8，オ = 0，カ = 2，キ = 4

真题风格 7　对数约束下的最大值原创 · 对应题型：对数约束下乘积的最大值

实数 $x,y$ 满足 $x\ge1$，$y\ge1$，$xy^2=64$。令 $X=\log_2 x$，$Y=\log_2 y$。

(1) $X+2Y=\boxed{\text{ア}}$，且 $0\le Y\le\boxed{\text{イ}}$。

(2) $\log_2 x\cdot\log_2 y$ 的最大值为 $\dfrac{\boxed{\text{ウ}}}{\boxed{\text{エ}}}$，此时 $x=\boxed{\text{オ}}$，$y=\boxed{\text{カ}}\sqrt{\boxed{\text{キ}}}$。

(3) $xy$ 的最大值为 $\boxed{\text{クケ}}$，最小值为 $\boxed{\text{コ}}$。

解答
  1. (1) 两边取以 $2$ 为底的对数：$X+2Y=6$。$x\ge1\iff X\ge0\iff6-2Y\ge0\iff Y\le3$；$y\ge1\iff Y\ge0$。
  2. (2) $XY=(6-2Y)Y=-2\Bigl(Y-\dfrac32\Bigr)^2+\dfrac92$，$Y=\dfrac32$ 在 $[0,3]$ 内，最大值 $\dfrac92$。此时 $X=3$，$x=8$，$y=2^{\frac32}=2\sqrt2$。
  3. (3) $xy=2^{X+Y}=2^{6-Y}$，$Y$ 越小越大：$Y=0$ 时最大 $2^6=64$（$x=64,\ y=1$），$Y=3$ 时最小 $2^3=8$（$x=1,\ y=8$）。

各格答案：ア = 6，イ = 3，ウ = 9，エ = 2，オ = 8，カ = 2，キ = 2，クケ = 64，コ = 8

真题风格 8　对数给出二次方程的两根，求指数方程参数的最值原创 · 对应题型：由对数给定二次方程两根求指数方程参数最值

正数 $a,b$ 使得关于 $x$ 的二次方程 $x^2-5x+k=0$ 的两个解为 $\log_2 a,\ \log_2 b$（$k$ 为实数）。令 $s=a+b$。

(1) $ab=\boxed{\text{アイ}}$。因此 $x=\log_2 a,\ \log_2 b$ 也是指数方程 $4^x-s\cdot2^x+\boxed{\text{アイ}}=0$ 的解。

(2) $s=12$ 时，$k=\boxed{\text{ウ}}$。

(3) $s$ 的最小值为 $\boxed{\text{エ}}\sqrt{\boxed{\text{オ}}}$，此时 $\log_2 a=\dfrac{\boxed{\text{カ}}}{\boxed{\text{キ}}}$，$k=\dfrac{\boxed{\text{クケ}}}{\boxed{\text{コ}}}$。

解答
  1. (1) 根与系数关系：$\log_2 a+\log_2 b=5$，即 $\log_2 ab=5$，$ab=32$。于是 $a,b$ 是 $u^2-su+32=0$ 的两根；令 $u=2^x$，$x=\log_2 a,\ \log_2 b$ 满足 $4^x-s\cdot2^x+32=0$。
  2. (2) $u^2-12u+32=0$，$(u-4)(u-8)=0$，$\{a,b\}=\{4,8\}$，$\log_2 a,\ \log_2 b$ 为 $2,3$，$k=2\cdot3=6$。
  3. (3) 由算术—几何平均不等式 $s=a+b\ge2\sqrt{ab}=2\sqrt{32}=8\sqrt2$，等号当 $a=b=\sqrt{32}=2^{\frac52}$ 时成立（此时二次方程有重根）。
  4. 此时 $\log_2 a=\dfrac52$，$k=\log_2 a\cdot\log_2 b=\dfrac{25}{4}$。（另解：令 $X=\log_2 a$，$s=2^X+2^{5-X}$，$k=X(5-X)$，两者都在 $X=\dfrac52$ 处取最值。）

各格答案：アイ = 32，ウ = 6，エ = 8，オ = 2，カ = 5，キ = 2，クケ = 25，コ = 4
