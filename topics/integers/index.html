1 倍数判定法

倍数の判定法

若 $a=bk$（$k$ 为整数），则称 $a$ 是 $b$ 的倍数（倍数），$b$ 是 $a$ 的约数（約数）。下表不必做除法，看数字就能判断：

倍数判定条件
$2$个位是偶数
$5$个位是 $0$ 或 $5$
$4$末两位组成的数是 $4$ 的倍数
$8$末三位组成的数是 $8$ 的倍数
$3$各位数字之和（各位の和）是 $3$ 的倍数
$9$各位数字之和是 $9$ 的倍数
$6$同时是 $2$ 和 $3$ 的倍数
$11$（参考）从个位起奇数位之和与偶数位之和的差是 $11$ 的倍数（含 $0$）

为什么成立？以三位数为例，

$$100a+10b+c=9(11a+b)+(a+b+c),$$

前一部分必是 $9$ 的倍数（也是 $3$ 的倍数），所以整除性只取决于 $a+b+c$。而 $100$ 是 $4$ 的倍数、$1000$ 是 $8$ 的倍数，所以只看末两位、末三位。

例：$7128$ 的数字和为 $18$，是 $9$ 的倍数；末三位 $128=8\times 16$，是 $8$ 的倍数。$8$ 与 $9$ 没有公共素因数，所以 $7128$ 是 $72$ 的倍数。

易错：判定「$72$ 的倍数」要拆成互素的 $8$ 和 $9$。拆成 $6$ 和 $12$ 不行，因为同时是 $6$、$12$ 的倍数只能保证是 $12$ 的倍数。

2 素数与素因数分解

素数と素因数分解

素数（素数）是大于 $1$、正约数只有 $1$ 和自身的自然数；大于 $1$ 的非素数叫合成数（合成数）。$1$ 既不是素数也不是合数；$2$ 是唯一的偶素数。

判断 $n$ 是否为素数，只需用不超过 $\sqrt n$ 的素数试除。例如 $\sqrt{221}<15$，试到 $13$ 时得 $221=13\times 17$。

每个大于 $1$ 的自然数都能唯一地写成素数之积（不计顺序）。设 $N=p^a q^b r^c$（$p,q,r$ 为不同素数），则：

正约数的个数：$(a+1)(b+1)(c+1)$
正约数的总和：$(1+p+\dots+p^a)(1+q+\dots+q^b)(1+r+\dots+r^c)$

例：$360=2^3\cdot 3^2\cdot 5$，正约数共 $4\cdot 3\cdot 2=24$ 个，总和为 $15\cdot 13\cdot 6=1170$。

常见用法

  • 平方数（平方数）：所有素因数的指数都是偶数。立方数：指数都是 $3$ 的倍数。例如要使 $84n$ 成为平方数，把 $84=2^2\cdot 3\cdot 7$ 中指数为奇数的补齐。
  • 阶乘中素因数的个数：$n!$ 中素因数 $p$ 的指数为 $\left\lfloor\dfrac{n}{p}\right\rfloor+\left\lfloor\dfrac{n}{p^2}\right\rfloor+\left\lfloor\dfrac{n}{p^3}\right\rfloor+\cdots$。
  • 末尾 $0$ 的个数：等于因数 $10=2\cdot 5$ 的个数，而 $5$ 比 $2$ 少，所以数 $5$ 的指数。

3 最大公约数与最小公倍数

最大公約数（G）・最小公倍数（L）・互いに素

素因数分解后，$G$ 取各素因数的较小指数，$L$ 取较大指数：

$$84=2^2\cdot 3\cdot 7,\quad 126=2\cdot 3^2\cdot 7\ \Longrightarrow\ G=2\cdot 3\cdot 7=42,\quad L=2^2\cdot 3^2\cdot 7=252.$$

最大公约数为 $1$ 时，称两数互素（互いに素）。

核心公式：设正整数 $a,b$ 的最大公约数为 $G$、最小公倍数为 $L$，则可写成

$$a=Ga',\quad b=Gb',\qquad L=Ga'b',\qquad ab=GL.$$

其中 $a',b'$ 互素。

题目给出 $G$ 和 $L$ 求 $a,b$ 时，先求 $a'b'=L/G$，再枚举互素的分解。

互素有一条常用性质：若 $a,b$ 互素且 $ak$ 是 $b$ 的倍数，则 $k$ 是 $b$ 的倍数。解不定方程时就靠这一条。

4 整数的除法

整数の割り算 — 商と余り

除法定理：对整数 $a$ 和正整数 $b$，存在唯一一对整数 $q,r$ 满足

$$a=bq+r,\qquad 0\le r<b.$$

$q$ 叫商（商），$r$ 叫余数（余り）。

注意余数不能是负数：$-17=5\times(-4)+3$，所以 $-17$ 除以 $5$ 商 $-4$ 余 $3$。

余数的运算

设 $a,b$ 除以 $m$ 的余数分别为 $r,s$，则下列各式除以 $m$ 的余数相同：

$a+b$ 与 $r+s$
$a-b$ 与 $r-s$
$ab$ 与 $rs$
$a^k$ 与 $r^k$

因此求 $3^{2026}$ 这类大数的余数时，只需找余数的循环节。

按余数分类

整数可按除以 $m$ 的余数分成 $m$ 类，证明题常用：

  • 除以 $2$：$2k,\ 2k+1$（偶数偶数、奇数奇数）；
  • 除以 $3$：$3k,\ 3k\pm 1$，由此 $n^2$ 除以 $3$ 的余数只能是 $0$ 或 $1$；
  • 奇数的平方：$(2k+1)^2=4k(k+1)+1$，$k(k+1)$ 是偶数，所以它除以 $8$ 余 $1$。

连续整数之积（連続する整数の積）：连续 $2$ 个整数之积是 $2$ 的倍数，连续 $3$ 个整数之积是 $6$ 的倍数。遇到 $n^3-n=(n-1)n(n+1)$ 要立刻想到这一点。

5 欧几里得互除法

ユークリッドの互除法

原理：若 $a=bq+r$，则 $\gcd(a,b)=\gcd(b,r)$。

因为 $a,b$ 的公约数都能整除 $r=a-bq$，$b,r$ 的公约数都能整除 $a=bq+r$，两组公约数完全相同。反复用余数替换，数越来越小，余数为 $0$ 前的最后一个除数就是最大公约数。

$$\begin{aligned}252&=105\times 2+42\\105&=42\times 2+21\\42&=21\times 2+0\end{aligned}\qquad\Longrightarrow\ \gcd(252,105)=21.$$

倒推可以把 $21$ 表示成 $252$ 和 $105$ 的组合，这正是下一节解不定方程的工具：

$$21=105-42\times 2=105-(252-105\times 2)\times 2=105\times 5+252\times(-2).$$

交互演示：用正方形铺满长方形

互除法的几何意义：在长 $a$、宽 $b$ 的长方形里不断切下尽量多的最大正方形，每一步的商就是切下的个数，最后的正方形边长就是最大公约数。同一颜色表示同一步。

步被除数 = 除数 × 商 + 余数

6 一次不定方程

1次不定方程式 $ax+by=c$ の整数解

有解条件：$ax+by=c$ 有整数解 $\iff$ $c$ 是 $\gcd(a,b)$ 的倍数。特别地，$a,b$ 互素时 $ax+by=1$ 一定有整数解。

例如 $6x+9y=4$ 无整数解：左边总是 $3$ 的倍数，右边不是。

解法三步

  1. 找一组特解（特殊解）：系数小时直接试，系数大时用互除法倒推。
  2. 相减：把原方程与特解的等式相减，得 $a(x-x_0)=-b(y-y_0)$。
  3. 用互素性：$a,b$ 互素时 $x-x_0$ 是 $b$ 的倍数，于是得到一般解（一般解）：
$$x=x_0+bk,\qquad y=y_0-ak.$$

其中 $k$ 为任意整数。

例：解 $43x+19y=1$。互除法：$43=19\times 2+5$，$19=5\times 3+4$，$5=4\times 1+1$。倒推：

$$1=5-4=5-(19-5\times 3)=5\times 4-19=(43-19\times 2)\times 4-19=43\times 4+19\times(-9).$$

特解 $(x_0,y_0)=(4,-9)$，一般解为 $x=4+19k,\ y=-9-43k$。

常数不为 $1$ 时可以把特解乘上常数，也可以直接找更小的特解：$43x+19y=5$ 有特解 $(1,-2)$，所以 $x=1+19k,\ y=-2-43k$。

限定正整数解时：把一般解代入 $x>0,\ y>0$，解出 $k$ 的范围再数个数。系数小的也可以直接抓「某个未知数必是某数的倍数」来枚举。

7 记数法（n 进制）

記数法 — n進法

$n$ 进制（n進法）只用数字 $0,1,\dots,n-1$，各位的权是 $n$ 的幂。写法上在右下角标注底数，如 $2301_{(4)}$。

$n$ 进制 → 十进制：按权展开

$$2301_{(4)}=2\cdot 4^3+3\cdot 4^2+0\cdot 4+1=177.$$

小数部分权为 $n^{-1},n^{-2},\dots$：$0.101_{(2)}=\dfrac12+\dfrac18=\dfrac58$。

十进制 → $n$ 进制

  • 整数部分：反复除以 $n$，把余数由下往上读。例：$100\div 3$ 依次余 $1,0,2,0,1$，所以 $100=10201_{(3)}$。
  • 小数部分：反复乘以 $n$，把整数部分由上往下读。例：$0.625\times 2=1.25$，$0.25\times 2=0.5$，$0.5\times 2=1$，所以 $0.625=0.101_{(2)}$。

位数与数字的范围

$N$ 在 $n$ 进制下是 $k$ 位数 $\iff n^{k-1}\le N<n^k$。用字母表示各位数字时别忘了范围：$n$ 进制的各位数字满足 $0\le a\le n-1$，且最高位不为 $0$。

例题 4　余数原创

(1) 整数 $n,m$ 除以 $7$ 分别余 $3,5$。此时 $n+m$ 除以 $7$ 余 $\B{A}$，$nm$ 除以 $7$ 余 $\B{B}$，$n^2+m^2$ 除以 $7$ 余 $\B{C}$。

(2) $2^{100}$ 除以 $7$ 余 $\B{D}$。

  • B = 1
  • C = 6
  • D = 2

1倍数判定

四位数 $8a35$（$a$ 是一位数字）是 $9$ 的倍数时，$a$ 是多少？是 $11$ 的倍数时呢？

$9$ 的倍数：$a=2$；$11$ 的倍数：$a=6$

数字和 $16+a$ 为 $9$ 的倍数，得 $a=2$。奇偶位差 $(5+a)-(3+8)=a-6$ 为 $11$ 的倍数，得 $a=6$。

2倍数判定

五位数 $3a72b$ 是 $72$ 的倍数。求所有的数字组 $(a,b)$。

$(a,b)=(6,0),(7,8)$

$8$ 的倍数：末三位 $72b$ 中 $b=0$ 或 $8$。$9$ 的倍数：数字和 $12+a+b$。$b=0$ 时 $a=6$；$b=8$ 时 $a=7$。即 $36720$、$37728$。

3约数

求 $360$ 的正约数的个数与总和。

$24$ 个，总和 $1170$

$360=2^3\cdot 3^2\cdot 5$。个数 $4\cdot 3\cdot 2=24$；总和 $15\cdot 13\cdot 6=1170$。

4约数

$180$ 的正约数中，奇数有几个？

$6$ 个

$180=2^2\cdot 3^2\cdot 5$。奇约数不含 $2$，是 $3^2\cdot 5$ 的约数，共 $3\cdot 2=6$ 个。

5平方数

求使 $\sqrt{84n}$ 为整数的最小正整数 $n$，以及此时 $\sqrt{84n}$ 的值。

$n=21$，$\sqrt{84n}=42$

$84=2^2\cdot 3\cdot 7$，补上 $3\cdot 7=21$，$84\times 21=1764=42^2$。

7G 与 L

正整数 $a<b$ 的最大公约数为 $12$，最小公倍数为 $180$。求所有的 $(a,b)$。

$(a,b)=(12,180),(36,60)$

$a=12a'$，$b=12b'$，$a'b'=180\div 12=15$，$a',b'$ 互素且 $a'<b'$：$(1,15),(3,5)$。

9不定方程

求 $17x+23y=1$ 的一般解，以及 $x$ 为最小正整数时的解。

$x=-4+23k,\ y=3-17k$；最小正 $x$：$(x,y)=(19,-14)$

$23=17+6$，$17=6\times 2+5$，$6=5+1$。倒推 $1=6-5=6\times 3-17=23\times 3+17\times(-4)$。取 $k=1$ 得 $(19,-14)$。

$100$ 以下的正整数中，除以 $5$ 余 $3$、除以 $7$ 余 $4$ 的有哪些？
