1 倍数判定法

倍数の判定法

若 $a=bk$（$k$ 为整数），则称 $a$ 是 $b$ 的倍数（倍数），$b$ 是 $a$ 的约数（約数）。下表不必做除法，看数字就能判断：

倍数判定条件
$2$个位是偶数
$5$个位是 $0$ 或 $5$
$4$末两位组成的数是 $4$ 的倍数
$8$末三位组成的数是 $8$ 的倍数
$3$各位数字之和（各位の和）是 $3$ 的倍数
$9$各位数字之和是 $9$ 的倍数
$6$同时是 $2$ 和 $3$ 的倍数
$11$（参考）从个位起奇数位之和与偶数位之和的差是 $11$ 的倍数（含 $0$）

为什么成立？以三位数为例，

$$100a+10b+c=9(11a+b)+(a+b+c),$$

前一部分必是 $9$ 的倍数（也是 $3$ 的倍数），所以整除性只取决于 $a+b+c$。而 $100$ 是 $4$ 的倍数、$1000$ 是 $8$ 的倍数，所以只看末两位、末三位。

例：$7128$ 的数字和为 $18$，是 $9$ 的倍数；末三位 $128=8\times 16$，是 $8$ 的倍数。$8$ 与 $9$ 没有公共素因数，所以 $7128$ 是 $72$ 的倍数。

易错：判定「$72$ 的倍数」要拆成互素的 $8$ 和 $9$。拆成 $6$ 和 $12$ 不行，因为同时是 $6$、$12$ 的倍数只能保证是 $12$ 的倍数。

判定法的统一推导：任何正整数都可以按位展开，如四位数 $N=1000a+100b+10c+d$。判定法的思路都一样：把 $N$ 分成「一定是倍数的部分」和「剩下的部分」，整除性只由后者决定。

除数关键事实结论
$2,\ 5$$10$ 是 $2$ 和 $5$ 的倍数，所以十位以上的部分都是倍数只看个位
$4$$100=4\times 25$，所以百位以上的部分都是倍数只看末两位
$8$$1000=8\times 125$，所以千位以上的部分都是倍数只看末三位
$3,\ 9$$10^k-1=99\cdots 9$ 是 $9$ 的倍数，所以 $10^k$ 除以 $9$ 余 $1$只看数字和
$11$$10=11-1$，所以 $10^k$ 除以 $11$ 的余数在 $1$ 与 $-1$（即 $10$）之间交替看奇偶位之差

以四位数为例验证 $11$ 的判定：$1000a+100b+10c+d=11(91a+9b+c)+(b+d-a-c)$，前一部分是 $11$ 的倍数，所以只需看 $(b+d)-(a+c)$。

为什么 $72$ 要拆成互素的两个数？若 $N$ 同时是互素的 $m,n$ 的倍数，则 $N$ 的素因数分解同时包含 $m$ 和 $n$ 的全部素因数，且两者没有重叠，所以 $N$ 是 $mn$ 的倍数。一般地，同时是 $m,n$ 的倍数只能推出是 $m,n$ 的最小公倍数的倍数。

补充例题　用 $4$ 和 $9$ 判定 $36$ 的倍数原创

五位数 $7a36b$（$a,b$ 是一位数字）是 $36$ 的倍数。求所有的数字组 $(a,b)$。

  1. 拆分：$36=4\times 9$，且 $4,9$ 互素，所以条件等价于同时是 $4$ 和 $9$ 的倍数。
  2. 用 $4$ 的条件：末两位 $6b$ 是 $4$ 的倍数，即 $60,64,68$，所以 $b=0,4,8$。
  3. 用 $9$ 的条件：数字和 $7+a+3+6+b=16+a+b$ 是 $9$ 的倍数。
  4. 分情况：$b=0$ 时 $16+a$ 为 $9$ 的倍数，$a=2$；$b=4$ 时 $20+a$ 为 $9$ 的倍数，$a=7$；$b=8$ 时 $24+a$ 为 $9$ 的倍数，$a=3$。
  5. 检验：$72360=36\times 2010$，$77364=36\times 2149$，$73368=36\times 2038$。

答案：$(a,b)=(2,0),\ (7,4),\ (3,8)$。

补充例题　用 $9$ 和 $11$ 判定 $99$ 的倍数原创

四位数 $a27b$（$a\ne 0$）是 $99$ 的倍数。求 $a,b$。

  1. 拆分：$99=9\times 11$，且 $9,11$ 互素。
  2. $9$ 的条件：$a+b+9$ 是 $9$ 的倍数。因为 $1\le a+b\le 18$，所以 $a+b=9$ 或 $18$。
  3. $11$ 的条件：从个位起，奇数位之和为 $b+2$，偶数位之和为 $7+a$，差 $b-a-5$ 是 $11$ 的倍数。因为 $-14\le b-a-5\le 3$，所以 $b-a-5=0$ 或 $-11$，即 $b-a=5$ 或 $-6$。
  4. 联立：$a+b$ 与 $b-a$ 的奇偶性必须相同。$a+b=9$（奇）只能配 $b-a=5$，得 $a=2,\ b=7$；$a+b=18$（偶）只能配 $b-a=-6$，得 $b=6,\ a=12$，不是一位数字，舍去。
  5. 检验：$2277=99\times 23$。

答案：$a=2,\ b=7$。

常见错误：

  • 把「数字和是 $3$ 的倍数」用到 $4$ 或 $8$ 上。数字和只对 $3,9$ 有效，例如 $13$ 与 $31$ 数字和相同，但 $4$ 的整除情况不必相同（$12$ 是 $4$ 的倍数，$21$ 不是）。
  • 判定 $8$ 时只看末两位。$116$ 的末两位 $16$ 是 $8$ 的倍数，但 $116=8\times 14+4$ 不是 $8$ 的倍数。
  • 判定 $11$ 时忘记差可以是 $0$ 或负数。差为 $0$、$\pm 11$、$\pm 22$ 都算。
  • 求数字时漏掉范围：$a,b$ 只能取 $0$ 到 $9$，且最高位不能为 $0$。

EJU 应试提示：题目出现带字母的多位数时，先用「只看末尾」的条件（$2,4,5,8$）缩小个位的可能，再用数字和求另一个字母，这样分情况最少。填空的方框数还可以提示答案的位数。

日语术语：倍数の判定法（ばいすうのはんていほう）：倍数判定法；下2桁（しもにけた）：末两位；下3桁（しもさんけた）：末三位；一の位（いちのくらい）：个位；各位の和（かくいのわ）：各位数字之和。

2 素数与素因数分解

素数と素因数分解

素数（素数）是大于 $1$、正约数只有 $1$ 和自身的自然数；大于 $1$ 的非素数叫合成数（合成数）。$1$ 既不是素数也不是合数；$2$ 是唯一的偶素数。

判断 $n$ 是否为素数，只需用不超过 $\sqrt n$ 的素数试除。例如 $\sqrt{221}<15$，试到 $13$ 时得 $221=13\times 17$。

每个大于 $1$ 的自然数都能唯一地写成素数之积（不计顺序）。设 $N=p^a q^b r^c$（$p,q,r$ 为不同素数），则：

正约数的个数：$(a+1)(b+1)(c+1)$
正约数的总和：$(1+p+\dots+p^a)(1+q+\dots+q^b)(1+r+\dots+r^c)$

例：$360=2^3\cdot 3^2\cdot 5$，正约数共 $4\cdot 3\cdot 2=24$ 个，总和为 $15\cdot 13\cdot 6=1170$。

为什么只试到 $\sqrt n$？若 $n=ab$ 是合数且 $1<a\le b$，则 $a^2\le ab=n$，所以 $a\le\sqrt n$。也就是说，合数必有一个不超过 $\sqrt n$ 的因数；这个因数再分解，就得到不超过 $\sqrt n$ 的素因数。如果试完都除不尽，$n$ 就是素数。

约数个数公式为什么成立？$N=p^aq^br^c$ 的正约数恰好是 $p^xq^yr^z$（$0\le x\le a,\ 0\le y\le b,\ 0\le z\le c$）。由分解的唯一性，不同的指数组对应不同的约数，而 $x,y,z$ 各有 $a+1,\ b+1,\ c+1$ 种选法，相乘即得个数。

约数总和公式为什么成立？把 $(1+p+\dots+p^a)(1+q+\dots+q^b)(1+r+\dots+r^c)$ 展开，每一项恰好是从三个括号各取一项相乘，即 $p^xq^yr^z$，每个约数恰好出现一次，所以展开式就是所有约数之和。

补充例题　素数判定与约数的分类原创

(1) 判断 $437$ 是否为素数。

(2) 求 $504$ 的正约数的个数和总和。

(3) $504$ 的正约数中，奇数有几个？偶数的总和是多少？

  1. (1) $20^2=400<437<441=21^2$，所以只需试 $2,3,5,7,11,13,17,19$。前七个都除不尽，而 $437=19\times 23$，所以是合数。
  2. (2) 分解：$504=2^3\cdot 63=2^3\cdot 3^2\cdot 7$。
  3. (2) 个数：$(3+1)(2+1)(1+1)=24$。总和：$(1+2+4+8)(1+3+9)(1+7)=15\cdot 13\cdot 8=1560$。
  4. (3) 奇约数不含 $2$，即 $3^2\cdot 7$ 的约数，共 $3\cdot 2=6$ 个，总和 $13\cdot 8=104$。
  5. (3) 偶约数的总和 = 全部总和 − 奇约数总和 $=1560-104=1456$；也可直接算 $(2+4+8)\cdot 13\cdot 8=1456$，两者一致。

答案：(1) 合数；(2) $24$ 个，总和 $1560$；(3) 奇约数 $6$ 个，偶约数总和 $1456$。

补充例题　由约数个数反求自然数原创

求正约数恰好有 $15$ 个的最小正整数。

  1. 约数个数等于各「指数 $+1$」之积，而 $15=15$ 或 $15=5\times 3$。
  2. 情形一：$N=p^{14}$，最小为 $2^{14}=16384$。
  3. 情形二：$N=p^4q^2$。要使 $N$ 最小，较大的指数应配给较小的素数，所以取 $p=2,\ q=3$，得 $N=2^4\cdot 3^2=144$。
  4. 比较两种情形，$144<16384$。

答案：$144$。

常见错误：

  • 把 $1$ 当作素数。素数要求大于 $1$；否则素因数分解就不再唯一（$6=2\cdot 3=1\cdot 2\cdot 3$）。
  • 约数个数算成指数之积。$360=2^3\cdot 3^2\cdot 5$ 的约数是 $4\cdot 3\cdot 2=24$ 个，不是 $3\cdot 2\cdot 1=6$ 个，因为指数可以取 $0$。
  • 分解没有彻底：$504=8\cdot 63$ 还不是素因数分解，$8$ 和 $63$ 都要继续拆开。
  • 试除时只试到 $\sqrt n$ 的一半，或漏掉 $7,11,13$ 这样的素数。

EJU 应试提示：分解大数时从小的素数依次试，每拆一次就把结果记下，用相乘来验算。熟记 $2^{10}=1024$ 以及 $91=7\times 13$、$119=7\times 17$、$221=13\times 17$ 这类看起来像素数的合数，可以省下不少时间。

日语术语：素数（そすう）：素数；合成数（ごうせいすう）：合数；素因数分解（そいんすうぶんかい）：素因数分解；正の約数（せいのやくすう）：正约数；約数の個数（やくすうのこすう）：约数的个数；約数の総和（やくすうのそうわ）：约数的总和。

常见用法

  • 平方数（平方数）：所有素因数的指数都是偶数。立方数：指数都是 $3$ 的倍数。例如要使 $84n$ 成为平方数，把 $84=2^2\cdot 3\cdot 7$ 中指数为奇数的补齐。
  • 阶乘中素因数的个数：$n!$ 中素因数 $p$ 的指数为 $\left\lfloor\dfrac{n}{p}\right\rfloor+\left\lfloor\dfrac{n}{p^2}\right\rfloor+\left\lfloor\dfrac{n}{p^3}\right\rfloor+\cdots$。
  • 末尾 $0$ 的个数：等于因数 $10=2\cdot 5$ 的个数，而 $5$ 比 $2$ 少，所以数 $5$ 的指数。

平方数的条件为什么是「指数都是偶数」？若 $N=M^2$，$M$ 的素因数分解中每个指数乘以 $2$ 就得到 $N$ 的指数，所以都是偶数；反过来，指数都是偶数时把每个指数减半就得到 $M$。由于分解唯一，这两个方向都成立。

阶乘的指数公式为什么要加多项？$1,2,\dots,n$ 中 $p$ 的倍数有 $\lfloor n/p\rfloor$ 个，每个至少贡献一个 $p$；其中 $p^2$ 的倍数还要多贡献一个，共 $\lfloor n/p^2\rfloor$ 个；依此类推。这样每个数中的 $p$ 都恰好被数到指数那么多次。

补充例题　平方数与阶乘的指数原创

(1) 求使 $\sqrt{540n}$ 为整数的最小正整数 $n$ 及此时根号的值。

(2) $100!$ 的末尾连续有几个 $0$？

(3) 求使 $40!$ 能被 $6^k$ 整除的最大整数 $k$。

  1. (1) $540=2^2\cdot 3^3\cdot 5$，指数为奇数的是 $3$ 和 $5$，各补一个，$n=15$。$540\times 15=8100=90^2$。
  2. (2) $5$ 的指数：$\lfloor 100/5\rfloor+\lfloor 100/25\rfloor=20+4=24$（$125>100$，后面都是 $0$）。
  3. (2) $2$ 的指数：$50+25+12+6+3+1=97$，比 $24$ 大，所以因数 $10$ 的个数由 $5$ 决定，为 $24$。
  4. (3) $6=2\times 3$，要同时数 $2$ 和 $3$。$2$ 的指数：$20+10+5+2+1=38$。$3$ 的指数：$\lfloor 40/3\rfloor+\lfloor 40/9\rfloor+\lfloor 40/27\rfloor=13+4+1=18$。
  5. (3) $k$ 不能超过两者中较小的，所以 $k=18$。

答案：(1) $n=15$，值为 $90$；(2) $24$ 个；(3) $k=18$。

常见错误：

  • 只除以 $5$ 不除以 $25,125$。$100!$ 的 $5$ 的指数若只算 $\lfloor 100/5\rfloor=20$ 就少了 $4$，因为 $25,50,75,100$ 各含两个 $5$。
  • 求立方数时按「补成偶数」处理。立方数要把指数补成 $3$ 的倍数。
  • 求 $6^k$、$12^k$ 这类合数幂时只看一个素因数。$12^k=2^{2k}3^k$，$2$ 的指数还要除以 $2$ 再比较。

EJU 应试提示：看到 $\sqrt{\square\, n}$、$\dfrac{\square}{n}$ 是平方数或「末尾 $0$ 的个数」，第一步都是素因数分解。题目问最小的 $n$ 时只补齐缺的部分，不要多乘。

日语术语：平方数（へいほうすう）：平方数；立方数（りっぽうすう）：立方数；階乗（かいじょう）：阶乘；指数（しすう）：指数；末尾（まつび）：末尾；連続して並ぶ（れんぞくしてならぶ）：连续排列。

3 最大公约数与最小公倍数

最大公約数（G）・最小公倍数（L）・互いに素

素因数分解后，$G$ 取各素因数的较小指数，$L$ 取较大指数：

$$84=2^2\cdot 3\cdot 7,\quad 126=2\cdot 3^2\cdot 7\ \Longrightarrow\ G=2\cdot 3\cdot 7=42,\quad L=2^2\cdot 3^2\cdot 7=252.$$

最大公约数为 $1$ 时，称两数互素（互いに素）。

核心公式：设正整数 $a,b$ 的最大公约数为 $G$、最小公倍数为 $L$，则可写成

$$a=Ga',\quad b=Gb',\qquad L=Ga'b',\qquad ab=GL.$$

其中 $a',b'$ 互素。

题目给出 $G$ 和 $L$ 求 $a,b$ 时，先求 $a'b'=L/G$，再枚举互素的分解。

互素有一条常用性质：若 $a,b$ 互素且 $ak$ 是 $b$ 的倍数，则 $k$ 是 $b$ 的倍数。解不定方程时就靠这一条。

$ab=GL$ 的推导：看某个素数 $p$，设它在 $a,b$ 中的指数分别为 $e,f$。$G$ 中的指数是 $\min(e,f)$，$L$ 中的指数是 $\max(e,f)$，而 $\min(e,f)+\max(e,f)=e+f$。所有素数都如此，所以 $GL$ 与 $ab$ 的分解完全相同。

$a',b'$ 为什么互素？若 $a',b'$ 有大于 $1$ 的公约数 $d$，则 $Gd$ 也是 $a,b$ 的公约数，且比 $G$ 大，与 $G$ 是最大公约数矛盾。

互素性质的理由：设 $a,b$ 互素且 $ak$ 是 $b$ 的倍数。$b$ 的每个素因数都整除 $ak$，但 $a$ 不含这些素因数，所以它们全部（连同指数）出现在 $k$ 中，即 $k$ 是 $b$ 的倍数。

补充例题　已知和与最大公约数原创

正整数 $a<b$ 满足 $a+b=96$，且最大公约数为 $12$。求所有的 $(a,b)$。

  1. 设 $a=12a',\ b=12b'$，其中 $a',b'$ 互素，$a'<b'$。
  2. 代入和：$12(a'+b')=96$，所以 $a'+b'=8$。
  3. 列举：$(1,7),(2,6),(3,5)$。其中 $(2,6)$ 的公约数为 $2$，不互素，舍去。
  4. 还原：$(1,7)\to(12,84)$，$(3,5)\to(36,60)$。
  5. 检验：$\gcd(12,84)=12$，$\gcd(36,60)=12$，和都是 $96$。

答案：$(a,b)=(12,84),\ (36,60)$。

补充例题　已知与某数的最大公约数原创

不超过 $100$ 的正整数 $n$ 中，满足 $\gcd(n,24)=6$ 的有几个？

  1. $n$ 是 $6$ 的倍数，设 $n=6m$，而 $24=6\times 4$。
  2. 于是 $\gcd(6m,6\times 4)=6\gcd(m,4)$，条件变为 $\gcd(m,4)=1$，即 $m$ 是奇数。
  3. 范围：$6m\le 100$，所以 $m\le 16$；奇数 $m=1,3,\dots,15$ 共 $8$ 个。
  4. 对应 $n=6,18,30,42,54,66,78,90$。

答案：$8$ 个。

常见错误：

  • 枚举 $a'b'=L/G$ 时没有检查互素。如 $L/G=12$ 时 $(2,6)$ 不合格，因为这时最大公约数会变成 $2G$。
  • 把 $ab=GL$ 用到三个数上。例如 $2,4,6$ 的积为 $48$，而 $G=2,\ L=12$，$GL=24$。这个公式只对两个数成立。
  • $G$ 取了较大指数或 $L$ 取了较小指数。可以用 $G\le a\le L$ 快速检验。

EJU 应试提示：凡是题目给出最大公约数，立即写 $a=Ga',\ b=Gb'$（$a',b'$ 互素），把问题化成小数字的枚举。算完用 $ab=GL$ 验算一次，错误多半能被发现。

4 整数的除法

整数の割り算 — 商と余り

除法定理：对整数 $a$ 和正整数 $b$，存在唯一一对整数 $q,r$ 满足

$$a=bq+r,\qquad 0\le r<b.$$

$q$ 叫商（商），$r$ 叫余数（余り）。

注意余数不能是负数：$-17=5\times(-4)+3$，所以 $-17$ 除以 $5$ 商 $-4$ 余 $3$。

除法定理为什么成立？存在性：把 $b$ 的所有倍数 $\dots,-b,0,b,2b,\dots$ 标在数轴上，它们把数轴分成长度为 $b$ 的区间，$a$ 必落在某个 $bq\le a<b(q+1)$ 中，取 $r=a-bq$，就有 $0\le r<b$。唯一性：若 $bq+r=bq_1+r_1$，则 $b(q-q_1)=r_1-r$；右边的绝对值小于 $b$，而左边是 $b$ 的倍数，所以两边都是 $0$。

补充例题　负数的除法与商余的条件原创

(1) 求 $-23$ 除以 $6$ 的商和余数。

(2) 正整数 $N$ 除以 $13$ 时商与余数相等。这样的 $N$ 有几个？最大的是多少？

(3) $100$ 除以正整数 $b$ 余 $4$。求 $b$ 的个数。

  1. (1) 找不超过 $-23$ 的最大的 $6$ 的倍数，是 $-24=6\times(-4)$。于是 $-23=6\times(-4)+1$，商 $-4$ 余 $1$。
  2. (2) 设商与余数都是 $q$，则 $N=13q+q=14q$。余数要满足 $0\le q<13$，又 $N>0$，所以 $q=1,2,\dots,12$。共 $12$ 个，最大的是 $14\times 12=168$。
  3. (3) $100=bq+4$，即 $bq=96$，所以 $b$ 是 $96$ 的约数；又余数小于除数，所以 $b>4$。
  4. (3) $96=2^5\cdot 3$ 的约数共 $12$ 个，去掉不超过 $4$ 的 $1,2,3,4$，剩下 $6,8,12,16,24,32,48,96$。

答案：(1) 商 $-4$，余 $1$；(2) $12$ 个，最大 $168$；(3) $8$ 个。

常见错误：

  • 把 $-23\div 6$ 写成商 $-3$ 余 $-5$。EJU 中的余数必须满足 $0\le r<b$，不能是负数。
  • 忘记余数小于除数。「除以 $b$ 余 $4$」隐含 $b>4$，所以 $b=1,2,3,4$ 都要舍去。
  • 商和余数相等时忘记 $q<13$ 这个限制，把 $q=13$ 也算进去。

EJU 应试提示：看到「除以 $b$ 余 $r$」，立刻写成 $a=bq+r$，再把条件 $0\le r<b$ 写在旁边。很多题目的解的个数就是由这个不等式决定的。

日语术语：割る数（わるすう）：除数；割られる数（わられるすう）：被除数；商（しょう）：商；余り（あまり）：余数；割り切れる（わりきれる）：整除。

余数的运算

设 $a,b$ 除以 $m$ 的余数分别为 $r,s$，则下列各式除以 $m$ 的余数相同：

$a+b$ 与 $r+s$
$a-b$ 与 $r-s$
$ab$ 与 $rs$
$a^k$ 与 $r^k$

因此求 $3^{2026}$ 这类大数的余数时，只需找余数的循环节。

为什么余数可以直接运算？设 $a=mx+r,\ b=my+s$。展开得 $a+b=m(x+y)+(r+s)$，$ab=m(mxy+xs+ry)+rs$，第一项都是 $m$ 的倍数，所以只有 $r+s$、$rs$ 影响余数。$a^k$ 就是把乘法重复 $k$ 次。

注意 $r+s$、$rs$ 本身可能不小于 $m$，或 $r-s$ 为负，这时要再加减 $m$ 的倍数调整到 $0$ 到 $m-1$ 之间。

补充例题　用循环与负余数算大数原创

(1) 求 $5^{2026}$ 除以 $7$ 的余数。

(2) 求 $2026^3$ 除以 $9$ 的余数。

(3) 求 $8^{101}$ 除以 $9$ 的余数。

(4) 整数 $n$ 除以 $7$ 余 $3$。求 $n^2+2n+5$ 除以 $7$ 的余数。

  1. (1) 列出 $5^k$ 除以 $7$ 的余数：$5,\ 4,\ 6,\ 2,\ 3,\ 1$，之后循环，周期为 $6$。
  2. (1) $2026=6\times 337+4$，对应第 $4$ 个，余数为 $2$。
  3. (2) 数字和 $2+0+2+6=10$，所以 $2026$ 除以 $9$ 余 $1$，$2026^3$ 的余数为 $1^3=1$。
  4. (3) $8=9-1$，所以 $8^{101}$ 与 $(-1)^{101}=-1$ 的余数相同。把 $-1$ 调整到范围内：$-1+9=8$。
  5. (4) 把 $n$ 换成余数 $3$：$9+6+5=20=7\times 2+6$，余数为 $6$。

答案：(1) $2$；(2) $1$；(3) $8$；(4) $6$。

常见错误：

  • 把余数相除。除法不能照搬：$20$ 与 $8$ 除以 $12$ 同余，但两边除以 $4$ 后的 $5$ 与 $2$ 除以 $12$ 余数不同。
  • 循环节数错。$2026\div 6$ 余 $4$ 要对应第 $4$ 项；余数为 $0$ 时对应最后一项，而不是第 $0$ 项。
  • 最后答案留下负数或大于除数的数，如把 $-1$ 或 $20$ 直接填上。

EJU 应试提示：找循环时，一旦余数出现 $1$，后面就重复了，可以就此停下。底数接近除数的倍数时（如 $8$ 对 $9$）用 $-1$ 代替，比列表更快。

日语术语：余り（あまり）：余数；周期（しゅうき）：周期；繰り返す（くりかえす）：重复、循环；循環（じゅんかん）：循环。

按余数分类

整数可按除以 $m$ 的余数分成 $m$ 类，证明题常用：

  • 除以 $2$：$2k,\ 2k+1$（偶数偶数、奇数奇数）；
  • 除以 $3$：$3k,\ 3k\pm 1$，由此 $n^2$ 除以 $3$ 的余数只能是 $0$ 或 $1$；
  • 奇数的平方：$(2k+1)^2=4k(k+1)+1$，$k(k+1)$ 是偶数，所以它除以 $8$ 余 $1$。

连续整数之积（連続する整数の積）：连续 $2$ 个整数之积是 $2$ 的倍数，连续 $3$ 个整数之积是 $6$ 的倍数。遇到 $n^3-n=(n-1)n(n+1)$ 要立刻想到这一点。

分类为什么可靠？由除法定理，每个整数恰好属于一类，所以逐类验证后就覆盖了全部整数，不重不漏。写成 $3k\pm 1$ 比写成 $3k+1,\ 3k+2$ 更方便，因为 $(3k\pm 1)^2=3(3k^2\pm 2k)+1$ 可以一次算完。

连续整数之积的理由：连续 $3$ 个整数中，必有一个除以 $3$ 余 $0$（三类余数各出现一次），又至少有一个偶数，而 $2,3$ 互素，所以积是 $6$ 的倍数。类似的恒等式也很有用：$n(n+1)(2n+1)=(n-1)n(n+1)+n(n+1)(n+2)$，右边两项都是连续 $3$ 个整数之积，所以左边总是 $6$ 的倍数。

补充例题　按余数分类的证明原创

(1) 证明：对任意整数 $n$，$n^5-n$ 是 $30$ 的倍数。

(2) 证明：不存在整数 $x,y$ 使 $x^2+y^2=2027$。

  1. (1) 分解：$n^5-n=n(n^4-1)=(n-1)n(n+1)(n^2+1)$。
  2. (1) $(n-1)n(n+1)$ 是连续 $3$ 个整数之积，所以是 $6$ 的倍数。因为 $30=6\times 5$ 且 $6,5$ 互素，只需再证是 $5$ 的倍数。
  3. (1) 按除以 $5$ 的余数分类：$n=5k$ 时因数 $n$ 是 $5$ 的倍数；$n=5k\pm 1$ 时因数 $n\mp 1$ 是 $5$ 的倍数；$n=5k\pm 2$ 时 $n^2+1=25k^2\pm 20k+5$ 是 $5$ 的倍数。
  4. (1) 五类都成立，所以 $n^5-n$ 是 $30$ 的倍数。
  5. (2) 平方数除以 $4$ 的余数：$(2k)^2=4k^2$ 余 $0$；$(2k+1)^2=4(k^2+k)+1$ 余 $1$。
  6. (2) 所以 $x^2+y^2$ 除以 $4$ 的余数只能是 $0,1,2$。而 $2027=4\times 506+3$ 余 $3$，矛盾，故不存在。

答案：两个结论均得证。

常见错误：

  • 分类不完整，例如除以 $5$ 只讨论 $5k,\ 5k+1$，或者只试几个具体的 $n$ 就当作证明。试例子只能帮助猜想，不能代替证明。
  • 混淆连续整数的结论：连续 $3$ 个整数之积是 $6$ 的倍数，但不一定是 $12$ 的倍数，如 $1\cdot 2\cdot 3=6$。
  • 把「$n^2$ 除以 $3$ 余 $0$ 或 $1$」记成「余 $0,1,2$」。$n^2$ 不可能除以 $3$ 余 $2$，这正是常用的反证依据。

EJU 应试提示：看到「对所有 $n$ 都是某数的倍数」，先因式分解找连续整数之积，再对剩下的因数分类。看到「无整数解」，试试取一个合适的模（常用 $3,4,8$），比较两边可能的余数。

日语术语：連続する整数の積（れんぞくするせいすうのせき）：连续整数之积；偶数（ぐうすう）：偶数；奇数（きすう）：奇数；場合分け（ばあいわけ）：分情况讨论；証明（しょうめい）：证明。

5 欧几里得互除法

ユークリッドの互除法

原理：若 $a=bq+r$，则 $\gcd(a,b)=\gcd(b,r)$。

因为 $a,b$ 的公约数都能整除 $r=a-bq$，$b,r$ 的公约数都能整除 $a=bq+r$，两组公约数完全相同。反复用余数替换，数越来越小，余数为 $0$ 前的最后一个除数就是最大公约数。

$$\begin{aligned}252&=105\times 2+42\\105&=42\times 2+21\\42&=21\times 2+0\end{aligned}\qquad\Longrightarrow\ \gcd(252,105)=21.$$

倒推可以把 $21$ 表示成 $252$ 和 $105$ 的组合，这正是下一节解不定方程的工具：

$$21=105-42\times 2=105-(252-105\times 2)\times 2=105\times 5+252\times(-2).$$

为什么一定会结束？每一步的余数都比除数小，所以余数序列 $r_1>r_2>\cdots\ge 0$ 是严格递减的非负整数，有限步后必为 $0$。设最后 $r_{k-1}=r_k q$，则 $\gcd(r_{k-1},r_k)=r_k$，再由原理一路等回去，$r_k$ 就是原来两数的最大公约数。

为什么比素因数分解更有效？$1071$、$462$ 这样的数不容易一眼分解，互除法只用除法就能得到结果，而且每两步余数至少减半，步数很少。

补充例题　互除法求 G、L 并约分原创

(1) 用互除法求 $1071$ 与 $462$ 的最大公约数和最小公倍数。

(2) 约分 $\dfrac{1071}{462}$。

(3) 把最大公约数表示成 $462x+1071y$ 的形式。

  1. (1) $1071=462\times 2+147$；$462=147\times 3+21$；$147=21\times 7+0$。所以 $G=21$。
  2. (1) $L=\dfrac{ab}{G}=\dfrac{1071\times 462}{21}=1071\times 22=23562$。
  3. (2) 分子分母都除以 $21$：$1071=21\times 51$，$462=21\times 22$，得 $\dfrac{51}{22}$。
  4. (3) 倒推：$21=462-147\times 3$，把 $147=1071-462\times 2$ 代入，得 $21=462-(1071-462\times 2)\times 3=462\times 7+1071\times(-3)$。
  5. (3) 检验：$3234-3213=21$。

答案：(1) $G=21,\ L=23562$；(2) $\dfrac{51}{22}$；(3) $x=7,\ y=-3$（表示法不唯一）。

补充例题　含字母的最大公约数原创

设 $n$ 为正整数。求 $3n+5$ 与 $n+1$ 的最大公约数。

  1. 把 $3n+5$ 当被除数：$3n+5=(n+1)\times 3+2$。
  2. 由原理，$\gcd(3n+5,n+1)=\gcd(n+1,2)$。
  3. $2$ 的约数只有 $1,2$，所以结果取决于 $n+1$ 的奇偶：$n$ 为奇数时 $n+1$ 是偶数，结果为 $2$；$n$ 为偶数时 $n+1$ 是奇数，结果为 $1$。

答案：$n$ 为奇数时为 $2$，$n$ 为偶数时为 $1$。

常见错误：

  • 把最后的余数 $0$ 或最后的商当作答案。答案是余数为 $0$ 那一步的除数。
  • 倒推时代入错位。每次只代入一个余数，并且把同类项（如 $462$ 的系数）合并后再继续。
  • 含字母时忘记讨论。$\gcd(n+1,2)$ 不是定值，要按 $n$ 的奇偶分情况。

EJU 应试提示：倒推容易出错，结束后把系数代回原式计算一次，只需几秒。如果题目已经给出 $\gcd$，也可以用 $a,b$ 同除以 $G$ 后再找特解，让数字变小。

日语术语：ユークリッドの互除法（ユークリッドのごじょほう）：欧几里得算法；約分（やくぶん）：约分；既約分数（きやくぶんすう）：最简分数；除法（じょほう）：除法。

交互演示：用正方形铺满长方形

互除法的几何意义：在长 $a$、宽 $b$ 的长方形里不断切下尽量多的最大正方形，每一步的商就是切下的个数，最后的正方形边长就是最大公约数。同一颜色表示同一步。

步被除数 = 除数 × 商 + 余数

几何意义为什么成立？把 $a\times b$ 的长方形切下 $q$ 个边长为 $b$ 的正方形，剩下 $r\times b$ 的长方形，这正是 $a=bq+r$。一个正方形若能铺满 $a\times b$，它的边长就必须同时整除 $a$ 和 $b$；切割过程保持这一点，所以最后的正方形边长就是最大公约数。

使用方法：先把滑块调到下题的 $a=168,\ b=64$，再逐步增加「显示步数」，把图形、表格和下面的算式对照着看。

补充例题　切正方形与铺地砖原创

长 $168$、宽 $64$ 的长方形。

(1) 按互除法的方式不断切下最大的正方形，一共切下几个？最后的正方形边长是多少？

(2) 用同样大小的正方形地砖无缝铺满这个长方形，地砖边长取整数且最大时，需要多少块？

  1. (1) 逐步相除：$168=64\times 2+40$（$2$ 个），$64=40\times 1+24$（$1$ 个），$40=24\times 1+16$（$1$ 个），$24=16\times 1+8$（$1$ 个），$16=8\times 2+0$（$2$ 个）。
  2. (1) 正方形个数等于所有商之和：$2+1+1+1+2=7$；最后边长为 $8$。
  3. (2) 地砖边长必须是 $168$ 和 $64$ 的公约数，最大为 $\gcd(168,64)=8$。
  4. (2) 块数为 $\dfrac{168}{8}\times\dfrac{64}{8}=21\times 8=168$。

答案：(1) $7$ 个，边长 $8$；(2) $168$ 块。

常见错误：

  • 把互除法的步数（本题 $5$ 步）当成正方形的个数（$7$ 个）。每一步切下的个数是商，可以大于 $1$。
  • 把两种问题混淆：互除法切出的正方形大小不等，铺地砖要求大小相同。两者只是最后的边长都等于 $\gcd$。

EJU 应试提示：应用题中「无缝铺满」「分成相同的组且不剩余」对应最大公约数；「同时到达」「拼成正方形」对应最小公倍数。先判断是 $G$ 还是 $L$，再计算。

日语术语：正方形（せいほうけい）：正方形；長方形（ちょうほうけい）：长方形；敷き詰める（しきつめる）：铺满；一辺の長さ（いっぺんのながさ）：边长。

6 一次不定方程

1次不定方程式 $ax+by=c$ の整数解

有解条件：$ax+by=c$ 有整数解 $\iff$ $c$ 是 $\gcd(a,b)$ 的倍数。特别地，$a,b$ 互素时 $ax+by=1$ 一定有整数解。

例如 $6x+9y=4$ 无整数解：左边总是 $3$ 的倍数，右边不是。

有解条件的推导：设 $G=\gcd(a,b)$。必要性：$a,b$ 都是 $G$ 的倍数，所以 $ax+by$ 总是 $G$ 的倍数，$c$ 也必须是。充分性：互除法倒推可以得到 $as+bt=G$；若 $c=Gm$，两边乘 $m$，得 $a(sm)+b(tm)=c$，这就是一组解。

所以解方程前先约分：两边同除以 $G$ 后系数互素，才能直接使用下面的一般解公式。

补充例题　先判断、再约分原创

(1) $14x+21y=5$ 有整数解吗？

(2) 求 $14x+21y=35$ 的全部整数解。

  1. (1) $\gcd(14,21)=7$，而 $5$ 不是 $7$ 的倍数，所以无整数解。
  2. (2) $35$ 是 $7$ 的倍数，两边除以 $7$：$2x+3y=5$，此时 $2,3$ 互素。
  3. (2) 观察得特解 $(x,y)=(1,1)$。
  4. (2) 相减：$2(x-1)=-3(y-1)$。$2,3$ 互素，所以 $x-1$ 是 $3$ 的倍数，设 $x-1=3k$，代回得 $y-1=-2k$。
  5. (2) 检验：$14(1+3k)+21(1-2k)=35+42k-42k=35$。

答案：(1) 无整数解；(2) $x=1+3k,\ y=1-2k$（$k$ 为整数）。

常见错误：

  • 没有约分就套公式。$14x+21y=35$ 若直接写 $x=1+21k,\ y=1-14k$，会漏掉 $k$ 的中间值对应的解，如 $(4,-1)$。
  • 只因为试不出解就断定无解。判断有无解要用 $\gcd$ 整除 $c$ 这个条件。

EJU 应试提示：题干问「有无整数解」时，一步求 $\gcd$ 就能定论。题干给出常数较大的方程时，先检查能否约分，数字变小后特解往往一眼可见。

日语术语：整数解（せいすうかい）：整数解；解なし（かいなし）：无解；係数（けいすう）：系数；定数（ていすう）：常数。

解法三步

  1. 找一组特解（特殊解）：系数小时直接试，系数大时用互除法倒推。
  2. 相减：把原方程与特解的等式相减，得 $a(x-x_0)=-b(y-y_0)$。
  3. 用互素性：$a,b$ 互素时 $x-x_0$ 是 $b$ 的倍数，于是得到一般解（一般解）：
$$x=x_0+bk,\qquad y=y_0-ak.$$

其中 $k$ 为任意整数。

例：解 $43x+19y=1$。互除法：$43=19\times 2+5$，$19=5\times 3+4$，$5=4\times 1+1$。倒推：

$$1=5-4=5-(19-5\times 3)=5\times 4-19=(43-19\times 2)\times 4-19=43\times 4+19\times(-9).$$

特解 $(x_0,y_0)=(4,-9)$，一般解为 $x=4+19k,\ y=-9-43k$。

常数不为 $1$ 时可以把特解乘上常数，也可以直接找更小的特解：$43x+19y=5$ 有特解 $(1,-2)$，所以 $x=1+19k,\ y=-2-43k$。

限定正整数解时：把一般解代入 $x>0,\ y>0$，解出 $k$ 的范围再数个数。系数小的也可以直接抓「某个未知数必是某数的倍数」来枚举。

第 3 步为什么得到全部解？由 $a(x-x_0)=-b(y-y_0)$，左边是 $a$ 的倍数，右边是 $b$ 的倍数。$a,b$ 互素时，$b$ 必须整除 $x-x_0$，设 $x-x_0=bk$；代回消去 $a$，得 $y-y_0=-ak$。反过来，任何整数 $k$ 代回都满足原方程，所以这个公式不多不少，恰好给出所有解。

符号的直观理解：$x$ 增加 $b$ 使左边增加 $ab$，$y$ 就要减少 $a$ 来抵消，所以两式中 $k$ 的符号相反。

补充例题　互除法求一般解原创

求 $27x+16y=1$ 的全部整数解。

  1. 互除法：$27=16\times 1+11$；$16=11\times 1+5$；$11=5\times 2+1$。
  2. 倒推：$1=11-5\times 2=11-(16-11)\times 2=11\times 3-16\times 2$。
  3. 再代入 $11=27-16$：$1=(27-16)\times 3-16\times 2=27\times 3+16\times(-5)$。特解为 $(3,-5)$。
  4. 一般解：$x=3+16k,\ y=-5-27k$。
  5. 检验：$27\times 3+16\times(-5)=81-80=1$。

答案：$x=3+16k,\ y=-5-27k$（$k$ 为整数）。

补充例题　限定正整数解原创

求 $7x+11y=200$ 的所有正整数解，并求 $x+y$ 的最小值。

  1. $7x=200-11y$ 要是 $7$ 的倍数。依次试 $y=1$：$200-11=189=7\times 27$，所以特解为 $(27,1)$。
  2. 一般解：$x=27-11k,\ y=1+7k$。
  3. 限定范围：$x>0$ 得 $k<\dfrac{27}{11}$，$y>0$ 得 $k>-\dfrac17$，所以 $k=0,1,2$。
  4. 对应 $(27,1),\ (16,8),\ (5,15)$。
  5. $x+y=28-4k$，随 $k$ 增大而减小，$k=2$ 时最小，为 $20$。

答案：$(x,y)=(27,1),(16,8),(5,15)$；$x+y$ 的最小值为 $20$。

补充例题　余数问题化为不定方程原创

求除以 $7$ 余 $2$、除以 $11$ 余 $5$ 的最小三位数。

  1. 设 $n=7x+2=11y+5$，整理得 $7x-11y=3$。
  2. 试 $x=2$：$14-11=3$，所以 $y=1$，$n=7\times 2+2=16$。
  3. 一般解为 $x=2+11k,\ y=1+7k$，代回得 $n=7(2+11k)+2=16+77k$，所以 $n$ 每隔 $7\times 11=77$ 出现一次。
  4. 依次为 $16,\ 93,\ 170,\dots$，最小的三位数是 $170$。
  5. 检验：$170=7\times 24+2=11\times 15+5$。

答案：$170$。

常见错误：

  • 一般解的符号写反，如写成 $x=3+16k,\ y=-5+27k$。写完代回原方程，$k$ 的项必须抵消。
  • $x,y$ 的周期写反：$x$ 的周期是 $y$ 的系数 $b$，$y$ 的周期是 $x$ 的系数 $a$。
  • 限定范围时把 $k<\dfrac{27}{11}$ 算成 $k\le 3$，或者把「正整数」当成「非负整数」，多算了 $0$。
  • 余数问题中周期用了 $7+11$。周期应是两个除数的最小公倍数。

EJU 应试提示：填空题的一般解可能因特解不同而写法不同，要按题目要求（如「$x$ 为最小正整数」）确定唯一的一组。题中明确要求「最小」「最大」时，把一般解代入后看单调性，不必逐个列举。

日语术语：特殊解（とくしゅかい）：特解；一般解（いっぱんかい）：一般解；自然数の組（しぜんすうのくみ）：自然数组；代入（だいにゅう）：代入；最小値（さいしょうち）：最小值。

7 记数法（n 进制）

記数法 — n進法

$n$ 进制（n進法）只用数字 $0,1,\dots,n-1$，各位的权是 $n$ 的幂。写法上在右下角标注底数，如 $2301_{(4)}$。

为什么表示是唯一的？$N=a_kn^k+\dots+a_1n+a_0$ 中，除 $a_0$ 外的每一项都是 $n$ 的倍数，而 $0\le a_0<n$，所以 $a_0$ 正是 $N$ 除以 $n$ 的余数，由除法定理它是唯一的。再对商重复同样的讨论，每一位都被唯一确定。这也说明进制转换的本质就是整数除法。

补充例题　由表示式求底数原创

(1) 数 $1234_{(n)}$ 中，底数 $n$ 最小可以是多少？

(2) $121_{(n)}$ 用十进制表示为 $49$。求 $n$。

  1. (1) $n$ 进制的数字不超过 $n-1$。出现了数字 $4$，所以 $n-1\ge 4$，$n\ge 5$，最小为 $5$。
  2. (2) 按权展开：$n^2+2n+1=49$，即 $(n+1)^2=49$。
  3. (2) $n+1=\pm 7$，得 $n=6$ 或 $n=-8$；底数是不小于 $2$ 的整数，所以 $n=6$。
  4. (2) 检验数字范围：数字 $2\le 5$ 合格；$36+12+1=49$。

答案：(1) $5$；(2) $n=6$。

常见错误：

  • 出现 $n$ 进制中不存在的数字，如 $5_{(5)}$、$2_{(2)}$。最大数字是 $n-1$。
  • 解出底数后没有舍去负值或不满足数字范围的值。

EJU 应试提示：题目中含字母底数时，把「数字 $<$ 底数」作为隐含条件写在草稿上，常用它来筛选答案。

日语术语：n進法（エヌしんほう）：n 进制；記数法（きすうほう）：记数法；底（てい）：底；位取り（くらいどり）：数位。

$n$ 进制 → 十进制：按权展开

$$2301_{(4)}=2\cdot 4^3+3\cdot 4^2+0\cdot 4+1=177.$$

小数部分权为 $n^{-1},n^{-2},\dots$：$0.101_{(2)}=\dfrac12+\dfrac18=\dfrac58$。

为什么这样展开？这就是记数法的定义：从右起第 $k$ 位（从 $0$ 数）的权是 $n^k$，每位数字表示有几个这样的权。小数点后第 $k$ 位的权是 $n^{-k}$，规律完全相同。

更快的算法（逐次乘）：$a_3n^3+a_2n^2+a_1n+a_0=\bigl(((a_3n+a_2)n+a_1)n+a_0\bigr)$，从最高位起「乘 $n$ 加下一位」，数字大时能减少计算量。

补充例题　含小数的按权展开原创

把下列各数化为十进制：(1) $3142_{(5)}$；(2) $0.23_{(4)}$；(3) $12.21_{(3)}$。

  1. (1) 按权展开：$3\cdot 125+1\cdot 25+4\cdot 5+2=375+25+20+2=422$。
  2. (1) 用逐次乘验算：$3\to 3\times 5+1=16\to 16\times 5+4=84\to 84\times 5+2=422$。
  3. (2) $\dfrac24+\dfrac{3}{16}=\dfrac{8+3}{16}=\dfrac{11}{16}=0.6875$。
  4. (3) 整数部分：$1\cdot 3+2=5$。小数部分：$\dfrac23+\dfrac19=\dfrac79$。合计 $5+\dfrac79=\dfrac{52}{9}$。

答案：(1) $422$；(2) $\dfrac{11}{16}$；(3) $\dfrac{52}{9}$。

常见错误：

  • 把最低位的权当成 $n$。个位的权是 $n^0=1$，所以 $4$ 位数的最高位的权是 $n^3$，不是 $n^4$。
  • 小数部分的权写成 $n,n^2$。小数点后第一位的权是 $\dfrac1n$。
  • 把 $12.21_{(3)}$ 的整数和小数部分混在一起算。分开算再相加最稳。

EJU 应试提示：答案要求分数时要约到最简；若小数部分的分母是 $n$ 的幂，化成十进制小数前先判断能否除尽。

日语术语：小数（しょうすう）：小数；整数部分（せいすうぶぶん）：整数部分；小数部分（しょうすうぶぶん）：小数部分；既約分数（きやくぶんすう）：最简分数。

十进制 → $n$ 进制

  • 整数部分：反复除以 $n$，把余数由下往上读。例：$100\div 3$ 依次余 $1,0,2,0,1$，所以 $100=10201_{(3)}$。
  • 小数部分：反复乘以 $n$，把整数部分由上往下读。例：$0.625\times 2=1.25$，$0.25\times 2=0.5$，$0.5\times 2=1$，所以 $0.625=0.101_{(2)}$。

整数部分为什么由下往上读？$N=a_kn^k+\dots+a_1n+a_0$，第一次除以 $n$ 的余数是最低位 $a_0$，商是 $a_kn^{k-1}+\dots+a_1$；再除一次得 $a_1$，以此类推。所以先得到的是低位，写答案时要倒过来读。

小数部分为什么由上往下读？$x=0.b_1b_2b_3\cdots_{(n)}$ 乘以 $n$，小数点右移一位，得 $b_1.b_2b_3\cdots_{(n)}$，整数部分就是 $b_1$。先得到的是高位，所以顺着读。

补充例题　整数与小数的转换原创

(1) 把 $2025$ 化为五进制。

(2) 把 $0.6875$ 化为四进制。

(3) 把 $23.625$ 化为二进制。

  1. (1) $2025\div 5=405$ 余 $0$；$405\div 5=81$ 余 $0$；$81\div 5=16$ 余 $1$；$16\div 5=3$ 余 $1$；$3\div 5=0$ 余 $3$。由下往上读得 $31100_{(5)}$。
  2. (1) 检验：$3\cdot 625+1\cdot 125+1\cdot 25=1875+125+25=2025$。
  3. (2) $0.6875\times 4=2.75$，取 $2$；$0.75\times 4=3$，取 $3$，小数部分为 $0$，结束。由上往下读得 $0.23_{(4)}$。
  4. (3) 分开处理。整数部分：$23=16+4+2+1=10111_{(2)}$。
  5. (3) 小数部分：$0.625\times 2=1.25$（取 $1$），$0.25\times 2=0.5$（取 $0$），$0.5\times 2=1$（取 $1$），得 $0.101_{(2)}$。合起来为 $10111.101_{(2)}$。

答案：(1) $31100_{(5)}$；(2) $0.23_{(4)}$；(3) $10111.101_{(2)}$。

常见错误：

  • 整数部分顺着读。$100$ 的三进制写成 $10201$ 是对称的看不出错，但多数情况读反就错了，如 $23$ 不是 $11101_{(2)}$。
  • 小数部分倒着读，或把整数部分的方向搬过来。可以记成「除法倒读，乘法顺读」。
  • 乘完之后把整数部分也继续乘。应把取出的整数部分去掉，只用小数部分继续。
  • 以为有限小数换进制后仍是有限小数。十进制的 $0.1$ 化成二进制是 $0.000110011\cdots_{(2)}$，不断循环。

EJU 应试提示：转换后用按权展开验算一次。二进制转换时，把 $1,2,4,8,16,32,64,128,256,512,1024$ 记熟，直接拆成 $2$ 的幂之和往往比反复除法快。

日语术语：有限小数（ゆうげんしょうすう）：有限小数；循環小数（じゅんかんしょうすう）：循环小数；2進法（にしんほう）：二进制；5進法（ごしんほう）：五进制。

位数与数字的范围

$N$ 在 $n$ 进制下是 $k$ 位数 $\iff n^{k-1}\le N<n^k$。用字母表示各位数字时别忘了范围：$n$ 进制的各位数字满足 $0\le a\le n-1$，且最高位不为 $0$。

位数不等式的来历：$k$ 位数中最小的是 $100\cdots 0_{(n)}=n^{k-1}$，最大的是 $(n-1)(n-1)\cdots(n-1)_{(n)}=n^k-1$，所以 $n^{k-1}\le N\le n^k-1$，也就是 $n^{k-1}\le N<n^k$。

补充例题　位数与数字的条件原创

(1) $1000$ 在二进制下是几位数？

(2) 三进制下为四位、二进制下为六位的正整数有几个？

(3) 两位数 $ab_{(7)}$ 与 $ba_{(9)}$ 表示同一个数（$a,b$ 都不为 $0$）。求这个数。

  1. (1) $2^9=512\le 1000<1024=2^{10}$，所以 $k-1=9$，是 $10$ 位。
  2. (2) 三进制四位：$27\le N<81$；二进制六位：$32\le N<64$。
  3. (2) 取交集：$32\le N<64$，共 $64-32=32$ 个。
  4. (3) 按权展开：$7a+b=9b+a$，整理得 $6a=8b$，即 $3a=4b$。
  5. (3) 由 $3,4$ 互素，$a$ 是 $4$ 的倍数；$a,b$ 同时是七进制和九进制数字，满足 $1\le a,b\le 6$，所以 $a=4,\ b=3$。
  6. (3) 这个数为 $7\times 4+3=31$，检验 $9\times 3+4=31$。

答案：(1) $10$ 位；(2) $32$ 个；(3) $31$。

常见错误：

  • 把 $k$ 位的范围写成 $n^k\le N<n^{k+1}$。$k$ 位数的最高位权是 $n^{k-1}$，如三位的十进制数从 $10^2$ 开始。
  • 数个数时把右端点算进去。$32\le N<64$ 共 $32$ 个，不是 $33$ 个。
  • 数字范围只考虑一个底数。同时出现在两种进制中的数字，要满足较小底数的限制。

EJU 应试提示：求某个进制下的位数时，先列出该底数的幂再比较，不要逐次相除。题目出现 $ab_{(n)}$ 的形式时，注意它表示 $an+b$，而不是乘积 $ab$。

日语术语：桁（けた）：位（数位）；桁数（けたすう）：位数；最高位（さいこうい）：最高位；3桁の数（さんけたのかず）：三位数。

交互演示：进制转换

二进制与八进制、四进制的关系：因为 $8=2^3$、$4=2^2$，把二进制数从右起每 $3$ 位（或每 $2$ 位）分成一组，每组正好对应八进制（或四进制）的一位。这个方法不用经过十进制，可用上面的滑块验证。

补充例题　用分组法在进制之间转换原创

(1) 不经过十进制，把 $101101110_{(2)}$ 化为八进制和四进制，并用十进制检验。

(2) 把 $1024$ 分别化为四进制和八进制。

  1. (1) 从右起每 $3$ 位一组：$101\ |\ 101\ |\ 110$，分别是 $5,5,6$，所以是 $556_{(8)}$。
  2. (1) 从右起每 $2$ 位一组：$1\ |\ 01\ |\ 10\ |\ 11\ |\ 10$，分别是 $1,1,2,3,2$，所以是 $11232_{(4)}$。
  3. (1) 检验：$5\cdot 64+5\cdot 8+6=366$；$256+64+32+12+2=366$；演示中取十进制 $366$，底数 $8$ 和 $4$ 结果相同。
  4. (2) $1024=4^5$，所以是 $1$ 后面跟 $5$ 个 $0$：$100000_{(4)}$。
  5. (2) $1024=2\cdot 512=2\cdot 8^3$，所以是 $2000_{(8)}$。

答案：(1) $556_{(8)}$，$11232_{(4)}$；(2) $100000_{(4)}$，$2000_{(8)}$。

常见错误：

  • 分组时从左边开始。必须从个位（右边）开始，整数部分最左边不足一组时前面补 $0$。
  • 把滑块的「底数」当作数的位数。底数决定权的大小，位数由 $n^{k-1}\le N<n^k$ 决定。

EJU 应试提示：分组法是快速验算工具：二进制、四进制、八进制之间互换时，它比先化成十进制快得多，也不容易出现大数计算的错误。

日语术语：8進法（はっしんほう）：八进制；4進法（よんしんほう）：四进制；3進法（さんしんほう）：三进制；10進法（じっしんほう）：十进制。

8 原创 EJU 风格例题

以下题目均为本讲义原创，仅模仿 EJU 的填空形式，并非真题。

填空规则：每个方框字母对应一个数字（$0$–$9$），例如 $\B{AB}$ 是两位数；分数要约到最简。

例题 1　互除法与不定方程原创

(1) $1147$ 与 $899$ 的最大公约数为 $\B{AB}$，最小公倍数为 $\B{CDEFG}$。

(2) 方程 $37x+29y=1$ 的整数解中，$x$ 为最小正整数的解是 $x=\B{HI}$，$y=-\B{JK}$。

(3) 方程 $1147x+899y=31000$ 的正整数解只有一组：$x=\B{L}$，$y=\B{MN}$。

  • A = 3
  • B = 1
  • C = 3
  • D = 3
  • E = 2
  • F = 6
  • G = 3
  • H = 1
  • I = 1
  • J = 1
  • K = 4
  • L = 9
  • M = 2
  • N = 3

(1) 互除法：$1147=899+248$，$899=248\times 3+155$，$248=155+93$，$155=93+62$，$93=62+31$，$62=31\times 2$，所以 $G=31$。又 $1147=31\times 37$，$899=31\times 29$，所以 $L=31\times 37\times 29=33263$。

(2) $37\times 11=407$，$29\times 14=406$，所以 $37\times 11+29\times(-14)=1$。一般解为 $x=11+29k$，$x$ 的最小正整数值是 $11$，此时 $y=-14$。

(3) 两边除以 $31$ 得 $37x+29y=1000$。对 $x=1,2,\dots$ 检验 $1000-37x$ 是否为 $29$ 的倍数，首次成立于 $x=9$：$1000-333=667=29\times 23$。一般解为 $x=9+29k,\ y=23-37k$，$k=0$ 时为正整数解；$k\ge 1$ 时 $y<0$，$k\le -1$ 时 $x<0$，故只有 $(x,y)=(9,23)$。

解题思路：第 (3) 问先约分，把大系数方程化成 $37x+29y=1000$。(2) 的结果也能用：两边乘 $1000$ 得特解 $(11000,-14000)$，但数字太大，所以这里直接试小的 $x$。检验：$37\times 9+29\times 23=333+667=1000$。

例题 2　素因数分解与约数原创

(1) $720=2^{\B{A}}\cdot 3^{\B{B}}\cdot 5$。

(2) $720$ 的正约数共有 $\B{CD}$ 个，它们的总和为 $\B{EFGH}$。

(3) 使 $720m$ 为平方数的最小正整数 $m$ 是 $\B{I}$，此时 $\sqrt{720m}=\B{JK}$。

(4) 使 $720n$ 为立方数的最小正整数 $n$ 是 $\B{LMN}$。

  • A = 4
  • B = 2
  • C = 3
  • D = 0
  • E = 2
  • F = 4
  • G = 1
  • H = 8
  • I = 5
  • J = 6
  • K = 0
  • L = 3
  • M = 0
  • N = 0

(1) $720=16\times 45=2^4\cdot 3^2\cdot 5$。

(2) 个数 $(4+1)(2+1)(1+1)=30$；总和 $(1+2+4+8+16)(1+3+9)(1+5)=31\cdot 13\cdot 6=2418$。

(3) 只有 $5$ 的指数是奇数，所以 $m=5$，$720\times 5=3600=60^2$。

(4) 指数要补成 $3$ 的倍数：$2^4\to 2^6$ 需 $2^2$，$3^2\to 3^3$ 需 $3$，$5\to 5^3$ 需 $5^2$。$n=4\cdot 3\cdot 25=300$，$720\times 300=216000=60^3$。

解题思路：第 (3)(4) 问的通法：把 $720m$ 的每个指数补到偶数或 $3$ 的倍数，且只补到最近的倍数才最小。也可用指数减半、除以 $3$ 直接求根：$2^4\cdot 3^2\cdot 5^2=(2^2\cdot 3\cdot 5)^2=60^2$；$2^6\cdot 3^3\cdot 5^3=(2^2\cdot 3\cdot 5)^3=60^3$。

例题 3　n 进制原创

例题 4　余数原创

(3) 对所有正整数 $n$，$n^3+5n$ 都能被 $\B{E}$ 整除，且 $\B{E}$ 是具有此性质的最大整数。

  • A = 1
  • B = 1

1倍数判定

四位数 $8a35$（$a$ 是一位数字）是 $9$ 的倍数时，$a$ 是多少？是 $11$ 的倍数时呢？

$9$ 的倍数：$a=2$；$11$ 的倍数：$a=6$

数字和 $16+a$ 为 $9$ 的倍数，得 $a=2$。奇偶位差 $(5+a)-(3+8)=a-6$ 为 $11$ 的倍数，得 $a=6$。

详细步骤：$9$ 的倍数：$8+a+3+5=16+a$，$0\le a\le 9$ 时 $16\le 16+a\le 25$，其中 $9$ 的倍数只有 $18$，所以 $a=2$（$8235=9\times 915$）。$11$ 的倍数：$a-6$ 的范围是 $-6$ 到 $3$，只有 $0$ 是 $11$ 的倍数，所以 $a=6$（$8635=11\times 785$）。

2倍数判定

五位数 $3a72b$ 是 $72$ 的倍数。求所有的数字组 $(a,b)$。

$(a,b)=(6,0),(7,8)$

$8$ 的倍数：末三位 $72b$ 中 $b=0$ 或 $8$。$9$ 的倍数：数字和 $12+a+b$。$b=0$ 时 $a=6$；$b=8$ 时 $a=7$。即 $36720$、$37728$。

详细步骤：$72=8\times 9$，且 $8,9$ 互素。$72b$ 中，$720=8\times 90$、$728=8\times 91$，其余 $b$ 都不行。$b=0$：$12+a$ 是 $9$ 的倍数，$a=6$。$b=8$：$20+a$ 是 $9$ 的倍数，$a=7$。检验：$36720=72\times 510$，$37728=72\times 524$。

3约数

求 $360$ 的正约数的个数与总和。

$24$ 个，总和 $1170$

$360=2^3\cdot 3^2\cdot 5$。个数 $4\cdot 3\cdot 2=24$；总和 $15\cdot 13\cdot 6=1170$。

详细步骤：分解：$360=36\times 10=2^3\cdot 3^2\cdot 5$。个数：每个指数加 $1$ 再相乘。总和：$1+2+4+8=15$，$1+3+9=13$，$1+5=6$，相乘得 $1170$。

4约数

$180$ 的正约数中，奇数有几个？

$6$ 个

$180=2^2\cdot 3^2\cdot 5$。奇约数不含 $2$，是 $3^2\cdot 5$ 的约数，共 $3\cdot 2=6$ 个。

详细步骤：全部约数共 $3\cdot 3\cdot 2=18$ 个，其中奇约数 $6$ 个，所以偶约数有 $18-6=12$ 个，也可以作为验算。

5平方数

求使 $\sqrt{84n}$ 为整数的最小正整数 $n$，以及此时 $\sqrt{84n}$ 的值。

$n=21$，$\sqrt{84n}=42$

$84=2^2\cdot 3\cdot 7$，补上 $3\cdot 7=21$，$84\times 21=1764=42^2$。

详细步骤：指数为奇数的素因数是 $3$ 和 $7$，$n$ 至少含 $3\cdot 7$，所以最小的 $n=21$。根号的值可直接由指数减半得到：$2^2\cdot 3^2\cdot 7^2=(2\cdot 3\cdot 7)^2=42^2$。

6阶乘

$30!$ 的末尾连续有几个 $0$？

$7$ 个

数 $5$ 的指数：$\left\lfloor\dfrac{30}{5}\right\rfloor+\left\lfloor\dfrac{30}{25}\right\rfloor=6+1=7$，而 $2$ 的指数更大。

详细步骤：$0$ 的个数等于因数 $10$ 的个数。$2$ 的指数为 $15+7+3+1=26$，$5$ 的指数为 $7$，取较小者。注意 $25$ 含两个 $5$，这就是第二项 $\lfloor 30/25\rfloor=1$ 的来源。

7G 与 L

正整数 $a<b$ 的最大公约数为 $12$，最小公倍数为 $180$。求所有的 $(a,b)$。

$(a,b)=(12,180),(36,60)$

$a=12a'$，$b=12b'$，$a'b'=180\div 12=15$，$a',b'$ 互素且 $a'<b'$：$(1,15),(3,5)$。

详细步骤：$a',b'$ 互素是必要条件，$15$ 的分解只有 $1\times 15$ 和 $3\times 5$，都互素，所以都保留。验算：$12\times 180=2160=36\times 60$，符合 $ab=GL$。

用互除法求 $2023$ 与 $1547$ 的最大公约数。

9不定方程

求 $17x+23y=1$ 的一般解，以及 $x$ 为最小正整数时的解。

$x=-4+23k,\ y=3-17k$；最小正 $x$：$(x,y)=(19,-14)$

$23=17+6$，$17=6\times 2+5$，$6=5+1$。倒推 $1=6-5=6\times 3-17=23\times 3+17\times(-4)$。取 $k=1$ 得 $(19,-14)$。

详细步骤：倒推细节：$1=6-5=6-(17-6\times 2)=6\times 3-17=(23-17)\times 3-17=23\times 3+17\times(-4)$，特解 $(x_0,y_0)=(-4,3)$。一般解 $x=-4+23k$ 中，$k=0$ 时 $x=-4<0$，$k=1$ 时 $x=19$ 是最小正值，此时 $y=3-17=-14$。检验：$323-322=1$。

10不定方程

$3x+5y=100$ 的正整数解有几组？

$6$ 组

特解 $(30,2)$，一般解 $x=30-5k,\ y=2+3k$。由 $x>0,\ y>0$ 得 $k=0,1,\dots,5$，共 $6$ 组：$(30,2),(25,5),(20,8),(15,11),(10,14),(5,17)$。

详细步骤：不等式：$30-5k>0$ 得 $k<6$；$2+3k>0$ 得 $k>-\dfrac23$，所以整数 $k$ 从 $0$ 到 $5$。也可以看出：$3x$ 除以 $5$ 要余 $0$，所以 $x$ 是 $5$ 的倍数，$x=5,10,\dots,30$，共 $6$ 个。

买每个 $120$ 日元的苹果和每个 $70$ 日元的橘子，各至少一个，共付 $1000$ 日元。各买了几个？

苹果 $6$ 个，橘子 $4$ 个

12余数

$100$ 以下的正整数中，除以 $5$ 余 $3$、除以 $7$ 余 $4$ 的有哪些？

$18,\ 53,\ 88$（共 $3$ 个）

$3^{2026}$ 的个位数字是多少？
