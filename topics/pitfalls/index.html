1. √(a²) 直接写成 a条件・前提

✗ 常见错误 $\sqrt{(x-3)^2}=x-3$。

✓ 正确做法 $\sqrt{a^2}=|a|$，按 $a$ 的正负分情况。

例　$x<3$ 时 $\sqrt{(x-3)^2}=3-x$。

相关：数与式 · 4 实数与根式　数与式 · 5 绝对值

2. 二次函数区间最值不分轴的位置条件・前提

✗ 常见错误 最小值一定在顶点。

✓ 正确做法 顶点不在区间内时，最值在端点；含参数时按轴在区间的左・中・右分类。

例　$y=(x-a)^2$ 在 $0\le x\le2$ 上：$a<0$ 时最小值为 $f(0)=a^2$。

相关：二次函数 · 2 最大与最小　二次函数 · 8 练习题

3. 忘了 x² 系数可能为 0条件・前提

✗ 常见错误 “$ax^2+bx+c=0$ 有实根 ⇔ $D\ge0$”，任何 $a$ 都适用。

✓ 正确做法 判别式只对二次方程（$a\ne0$）适用；$a=0$ 时要另外讨论一次方程。

例　$ax^2+2x+1=0$ 有实数解：$a=0$ 时也有解 $x=-\frac12$。

相关：二次函数 · 5 图像与二次方程　二次函数 · 4 二次方程的解

4. 对数的真数条件条件・前提

✗ 常见错误 解完 $\log_2(x-1)+\log_2(x+1)=3$ 直接取两个根。

✓ 正确做法 先写真数条件（$x-1>0$ 且 $x+1>0$），最后检查。

例　$x^2-1=8\Rightarrow x=\pm3$，但只有 $x=3$ 满足真数条件。

相关：指数函数与对数函数 · 3 对数的性质　指数函数与对数函数 · 4 对数函数与图像

5. 换元后忘了新变量的范围条件・前提

✗ 常见错误 令 $t=\sin x+\cos x$ 后，$t$ 取任意实数。

✓ 正确做法 换元必须同时求出新变量的范围：$t=\sqrt2\sin(x+\frac\pi4)\in[-\sqrt2,\sqrt2]$；$t=2^x>0$。

例　$4^x-2^{x+1}$ 的最小值：$t=2^x>0$，$t^2-2t\ge-1$（$t=1$ 时）。

相关：三角函数 · 6 三角函数的合成　三角函数 · 8 练习题　指数函数与对数函数 · 7 练习题

6. 等比数列求和忘了 r = 1条件・前提

✗ 常见错误 $S_n=\frac{a(1-r^n)}{1-r}$ 对所有 $r$。

✓ 正确做法 $r=1$ 时 $S_n=na$；公比含参数时要分开。

例　$1+x+x^2+\cdots+x^{n-1}$：$x=1$ 时为 $n$。

相关：数列 · 2 等比数列

7. 由 Sₙ 求 aₙ 不检查 n = 1条件・前提

✗ 常见错误 $a_n=S_n-S_{n-1}$ 对所有 $n$ 成立。

✓ 正确做法 该式只对 $n\ge2$ 成立；$a_1=S_1$ 要单独检查是否符合同一式子。

例　$S_n=n^2+1$：$a_1=2$，$n\ge2$ 时 $a_n=2n-1$（$n=1$ 时不符合）。

9. 换元积分不换积分区间条件・前提

✗ 常见错误 $\int_0^1 2x(x^2+1)^3dx$ 令 $t=x^2+1$ 后仍积 $0\to1$。

✓ 正确做法 积分区间要换成 $t$ 的范围（$1\to2$），或换回 $x$ 再代入。

例　$=\int_1^2t^3dt=\frac{15}4$。

10. 独立性的前提条件・前提

✗ 常见错误 $V(X+Y)=V(X)+V(Y)$ 总成立。

✓ 正确做法 和的期望总可加；方差相加需要 $X,Y$ 独立（或协方差为 0）。

例　$Y=X$ 时 $V(2X)=4V(X)\ne2V(X)$。

11. 均值不等式的等号条件条件・前提

✗ 常见错误 $x+\frac4x\ge2\sqrt4=4$，所以最小值 4（不看 $x$ 的范围）。

✓ 正确做法 需 $x>0$，并确认等号可取（$x=2$）；有范围限制（如 $x\ge3$）时等号取不到，要改用单调性。

例　$x\ge3$ 时 $x+\frac4x$ 的最小值是 $\frac{13}3$。

相关：各种式（式与证明・高次方程式） · 5 等式与不等式的证明

12. 一般式不一定是圆条件・前提

✗ 常见错误 $x^2+y^2+lx+my+n=0$ 一定表示圆。

✓ 正确做法 配方后右边须 > 0；= 0 是一点，< 0 无图形。

例　$x^2+y^2-2x+4y+k=0$ 表示圆 ⇔ $k<5$。

15. 面积用定积分不分上下符号・方向

✗ 常见错误 面积 $=\int_a^b f(x)dx$，结果为负就取绝对值。

✓ 正确做法 按交点分段，在每一段上用“上方函数 − 下方函数”；曲线穿过 $x$ 轴时正负部分不能抵消。

例　$\int_0^{2\pi}\sin x\,dx=0$，但所围面积为 4。

16. 复数的辐角范围符号・方向

✗ 常见错误 $\arg z$ 只取 $0$–$\pi$，或用 $\tan^{-1}$ 直接求不看象限。

✓ 正确做法 辐角由实部和虚部的符号确定象限，通常取 $0\le\theta<2\pi$ 或 $-\pi<\theta\le\pi$（看题目指定）。

例　$z=-1-i$：$\arg z=\frac54\pi$（不是 $\frac\pi4$）。

17. f′(a) = 0 就是极值概念混淆

✗ 常见错误 $y=x^3$ 在 $x=0$ 有极值。

✓ 正确做法 需要 $f^{\prime}$ 在 $a$ 两侧变号。由“在 $x=a$ 取极值”求出参数后要回代检验。

例　$y=x^3$：$f^{\prime}(0)=0$ 但单调递增，无极值。

18. 方差的线性变换概念混淆

✗ 常见错误 $V(2X+3)=2V(X)+3$。

✓ 正确做法 $V(aX+b)=a^2V(X)$，常数平移不改变方差；$\sigma(aX+b)=|a|\sigma(X)$。

例　$V(X)=4$ ⇒ $V(2X+3)=16$，$\sigma=4$。

24. 必要条件・充分条件方向反了读题・图表

✗ 常见错误 $p\Rightarrow q$ 时 $p$ 是 $q$ 的必要条件。

✓ 正确做法 $p\Rightarrow q$ 成立时：$p$ 是 $q$ 的充分条件，$q$ 是 $p$ 的必要条件。用集合：$P\subset Q$。
